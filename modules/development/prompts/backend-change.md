# Backend Change — правка схемы БД, API, auth, ролей и изоляции данных

Запускай, когда в проекте с реальной БД меняется модель данных, auth-флоу, роли или правила доступа к данным.

Нужно на входе: `docs/spec.md`, БД со схемой ORM (например, `prisma/schema.prisma`), API-роуты.

Порядок всегда один: **сначала `docs/spec.md`, потом схема и код.**

## Что меняется → что делать

| Что меняется | Алгоритм |
|---|---|
| Новое поле в сущности | `spec.md → Данные (модель)` → поле в схеме → миграция → API-роут (чтение/запись/валидация) → мок, если ещё используется |
| Новая сущность | `spec.md → Данные (модель)` → модель в схеме (связи, индексы, `userId` для пользовательских данных) → миграция → слайс в `entities/` → API-роуты |
| Изменился auth-флоу | раздел про авторизацию в `spec.md` (если нет — «Доступы и роли») → middleware и auth API-роуты |
| Добавилась роль | `spec.md → Доступы и роли` → проверка роли в middleware и в каждом затронутом API-роуте (не только в UI) |
| Изменилась изоляция данных | `spec.md` → фильтрация в API-роутах (каждый запрос ограничен владельцем/ролью) → тест-кейсы |

## Миграции

- Создай миграцию командой ORM (Prisma: `npx prisma migrate dev --name <что-изменилось>`), затем `npx prisma generate` и перезапусти dev-сервер.
- Если ORM предлагает сбросить (reset) локальную БД из-за дрейфа, а в ней есть ценные данные — не соглашайся, остановись и спроси.
- На проде миграции применяются только `migrate deploy` (через деплой-скрипт), не `migrate dev` и не `db push`.
- Новое обязательное поле в таблице с данными — задай default или сделай двухшаговую миграцию (nullable → заполнить → NOT NULL).

## Проверка

1. Изоляция: под вторым аккаунтом чужие записи недоступны (включая прямой запрос `/api/...?id=<чужой>`) — ответ 403/404.
2. Данные реально сохраняются в БД и читаются обратно.
3. Тест-кейсы обновлены, если менялись доступы или изоляция.
4. Изменение затронуло auth, роли или доступ к данным — прогони `modules/development/prompts/security-check.md` по diff.
5. Покажи diff спеки, схемы, миграции и кода.
