# Вайрфреймы и флоу

Цель — быстро показать путь пользователя серыми экранами, чтобы обсуждать UX-решения до дизайна и кода. Экран собирается
из общего набора компонентов (`.claude/skills/wireframes/`), флоу — JSON в проекте, страница — артефакт со стрелками,
прототипом и заметками.

## Когда
- Надо сравнить или согласовать сценарий: «как редактор поменяет текст и опубликует».
- Перед `screens-prototype` (прототип на коде) — чтобы не верстать то, что ещё спорно.
- Для разговора с клиентом или пользователями: кликабельный прототип вместо описания.
Не для визуального дизайна: цвета, шрифты, бренд — `design-system`, `ui-kit`.

## Шаги
1. **Сценарий.** Чей путь, с какой задачей, где начинается и чем заканчивается. Основание — из проекта: спека, ADR,
   находки, JTBD, бенчмарк. Если основания нет — сказать и предложить собрать (`/jtbd`, `/benchmark`).
2. **Список экранов.** Одно состояние на экран. Группы — фазы пути. Отметить, где решение спорное: там будет заметка.
3. **Флоу.** `docs/flows/<slug>.json` по `references/flow-format.md`. Тексты — настоящие для продукта, картинки — плашки.
   Каждое UX-решение — `note` на элементе с основанием (находка, ADR, источник). Кнопки шапки, которые есть на каждом
   экране, — `quiet`.
4. **Сборка и проверка.** `python3 <скилл>/scripts/build.py docs/flows/<slug>.json <выход>.html`. Ошибки чинить во флоу.
   Посмотреть доску и 2–3 экрана прототипа: ширина 1440 и 390, нет ошибок в консоли и горизонтальной прокрутки страницы.
5. **Публикация.** Артефакт из `<выход>.html`, тот же путь при обновлениях. Пользователю — ссылка и список решений,
   которые стоит обсудить (номера заметок).
6. **Коммит** `docs/flows/` в репозиторий проекта. Новый общий компонент — коммит в репозиторий Studio отдельно.

## Набор
Общие компоненты закрывают сайты и интерфейсы: раскладка, навигация, текст, поля, данные, сообщения, окна, медиа,
секции сайта. Не хватает — сначала спросить себя, общий ли это элемент: да → в `kit.js` (с `doc`, `props`, примером),
только для проекта → в `docs/flows/pack.js` проекта.
