# Текст без AI-следов — вычитка копирайта

Универсальный протокол для любого AI (Claude Code, Codex, Cursor). В Claude Code его можно обернуть в скилл `/avoid-ai-writing`; без скилла — выполнять по этому файлу.

Запускай, когда тексты уже на странице (лендинг, публичные страницы, маркетинговые тексты): Hero, подзаголовки, Features, «для кого», How it works, FAQ, CTA. Вычитывается копирайт, не код.

Нужно на входе: готовые тексты на странице; для профиля `landing` — `docs/landing-brief.md` (факты: job, результат, числа, возражения).

## Профили

- **`landing`** — строже обычного: промо-язык и инфляция значимости — главные враги; текст продаёт фактами из брифа.
- **обычный** — тот же чеклист, промо-блок применять мягче.

## Режимы

- **`rewrite`** (по умолчанию) — найти AI-маркеры → переписать → показать diff → второй проход.
- **`detect`** — только найти и пометить (текст нельзя менять или нужна быстрая проверка).

## Алгоритм

1. Собери все тексты страницы (`page.tsx` и компоненты Hero/Features/FAQ и т.п.).
2. Прогони по чеклисту (минимум P0 + P1).
3. Перепиши найденное, опираясь на факты из `docs/landing-brief.md` / `docs/spec.md`.
4. Покажи diff: было → стало, с пометкой, какой паттерн убран.
5. Второй проход: не появились ли новые штампы.

## Чеклист

### P0 — убрать сразу

- [ ] Артефакты чат-бота: «Конечно!», «Отличный вопрос!», «Надеюсь, это поможет».
- [ ] Заявления без доказательства: «гарантированный результат», «100% эффективность», «№1 на рынке».
- [ ] Инфляция значимости: «революционный», «поворотный момент», «меняет всё».

### P1 — убрать до публикации

**Слова-маркеры (RU):** «в современном мире», «на сегодняшний день», «ключевой момент», «комплексный подход», «тщательно подобранный», «инновационное решение», «выводит на новый уровень». В одном абзаце — максимум одно из «благодаря / обеспечивает / позволяет / способствует / направлен на».

**Псевдо-выгоды-затычки:** «всё в одном месте», «всё в одном окне», «всё в вебе / в браузере», «работает прямо в браузере», «интерфейс на русском». Заменить фактом (что именно, какой результат) или убрать.

**Конструкции:**
- [ ] Антитеза «не X, а Y» / «это не просто …, это …» — максимум одна на страницу, остальное утвердительно.
- [ ] Открытия-затычки: «давайте рассмотрим», «на этой странице мы…».
- [ ] Тройные перечисления «быстро, удобно и надёжно» — оставить только несущее смысл.
- [ ] Симметричные формулы «чем глубже X, тем точнее Y».
- [ ] Однотипные заголовки секций под копирку.

**Промо-язык (для `landing` — строго):**
- [ ] «команда профессионалов», «опытные специалисты» → кто, сколько, какой опыт.
- [ ] «индивидуальный подход» → что именно индивидуального.
- [ ] «современное оборудование/технологии» → конкретный тип/название.
- [ ] «динамично развивающийся», «процветающий» → факт или убрать.

**Открытие Hero:**
- [ ] Не начинать с «В современном мире…» / «На сегодняшний день…».
- [ ] Первое предложение — конкретика (что за продукт + job + результат).

### P2 — полировка

- [ ] Длина предложений варьируется: короткие (3–8 слов) и длинные (20+).
- [ ] Em-dash (—) в прозе не злоупотреблять (в списках `**Имя** — описание` нормально).
- [ ] Жирный — дозированно.
- [ ] Эмодзи в заголовках — нет.
- [ ] Финал секций конкретный (вывод или CTA), без «оставайтесь с нами» и «время покажет».
- [ ] «Более того / кроме того / также» — по делу, не как связки.
- [ ] Висячие предлоги и союзы (в, и, с, к, о, на, по, не, что…) привязаны к следующему слову неразрывным пробелом (`&nbsp;`), особенно в заголовках и Hero.

## Read-aloud тест

Прочитай вслух 2–3 случайных блока. Звучит как презентация на конференции или брошюра турагентства — переписать. Звучит как человек, который знает продукт, — ок.

## Переписать с нуля, а не патчить

5+ слов-маркеров, 3+ типа шаблонных конструкций, однородный ритм — перепиши блок заново: сначала одна фраза с главной мыслью из брифа, потом текст вокруг неё.

## Результат

Тексты переписаны: конкретно и по фактам, без промо-фраз, антитез-шаблонов и AI-маркеров. Показан diff было → стало.
