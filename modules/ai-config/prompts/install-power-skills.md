# Install Power Skills — готовые скиллы из каталога (документы и др.)

Запускай, когда нужны задачи за пределами кода: презентация, PDF-отчёт, таблица с расчётами, Word-документ — или когда ищешь готовый скилл под новую задачу.

Нужно на входе: Claude Code (CLI или расширение VS Code) и `.claude/settings.json` (воркспейса или проекта).

Базовый набор — официальный плагин Anthropic `document-skills` (четыре скилла, подхватываются сами по задаче, это не slash-команды):
- **`pdf`** — создать / прочитать / заполнить / объединить PDF;
- **`docx`** — документы Word: письма, ТЗ, отчёты, шаблоны с оглавлением и стилями;
- **`xlsx`** — таблицы: финмодель, бюджет, формулы, графики, чистка данных;
- **`pptx`** — презентации и питч-деки.

## Промт

```
Подключи официальный пак документных скиллов Anthropic (PDF / Word / Excel /
презентации). Открой .claude/settings.json (воркспейса, если библиотека общая) и:
— добавь маркетплейс anthropics/skills в раздел extraKnownMarketplaces под именем
  anthropic-agent-skills (источник: github, repo anthropics/skills);
— включи плагин document-skills@anthropic-agent-skills в разделе enabledPlugins.
Разделов нет — создай; остальные настройки не трогай. Потом скажи, как перезагрузить
окно, чтобы скиллы активировались.
```

В CLI можно и командами: `/plugin marketplace add anthropics/skills` → `/plugin install document-skills@anthropic-agent-skills`.

После правки: VS Code — `Cmd+Shift+P` → `Developer: Reload Window`, подтвердить установку маркетплейса и плагина; CLI — перезапустить сессию.

## Проверка

«Сделай презентацию из трёх слайдов по теме X» или «собери .xlsx с этими цифрами и формулой суммы» — должен получиться реальный файл `.pptx` / `.xlsx`, а не текст в чате.

## Как найти ещё

- Где искать: каталог https://claude.com/plugins и репозиторий https://github.com/anthropics/skills (`webapp-testing`, `brand-guidelines`, `canvas-design`, `theme-factory` и др.).
- Как оценить: что добавляет плагин и его context cost — каждый включённый плагин ест токены каждый ход. Ставить только под реальную задачу.

## Гигиена

Ненужное — выключить в `enabledPlugins` (`false` или удалить строку) и перезагрузить окно.

По желанию — заметка в `docs/memory/decisions/` проекта: что подключили и что пригодилось.
