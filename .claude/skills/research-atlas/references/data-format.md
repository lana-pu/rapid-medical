# Формат данных атласа

```
docs/research/
├── project.json
└── stages/
    ├── frame.json     (имя файла = id этапа из assets/stages.json)
    └── desk.json
```

Нет файла — этап «Не начат». Создавать пустые файлы не нужно.

## project.json

```json
{
  "title": "Атлас Acme",
  "product": "Acme",
  "eyebrow": "Acme · исследование для редизайна",
  "heading": "Атлас исследования",
  "lede": "Что знаем, откуда и чего не хватает. Этапы слева, несделанное ниже.",
  "owner": "Анна"
}
```

`owner` — кто принимает решения: подпись в списке «Решение за …». `title` — короткое имя страницы. `imgRoot` — папка с
`img/` от папки данных, если в атласе есть экраны.

## stages/<id>.json

```json
{
  "conclusions": ["Что из этого меняет решение"],
  "outputs": {
    "decision": [{"type": "text", "t": "…"}],
    "questions": [{"type": "table", "head": ["Вопрос", "Этап"], "rows": [["…", "…"]]}]
  },
  "open": [{"kind": "decision", "t": "Подтвердить главный сегмент"}],
  "confirmed": "2026-11-05",
  "skip": "Продукта ещё нет"
}
```

- Ключи `outputs` — разделы этапа из `stages.json`; лишний ключ — ошибка сборки.
- `open`: `kind` — `question` (не знаем) или `decision` (решает владелец).
- `confirmed` — дата подтверждения пользователем. С проставленным `confirmed` незаполненный этап не соберётся.
- `skip` — причина пропуска.

## Блоки

| type | Поля | Для чего |
|---|---|---|
| `text` | `t` | абзац |
| `sub` | `t` | подзаголовок внутри раздела |
| `fold` | `t`, `blocks` | свёрнутая группа: профиль, карточка исследования |
| `list` | `items` | список |
| `shots` | `items: [{img, cap}]` | экраны с подписями, клик открывает крупно; `img` — путь `img/….webp` от папки `imgRoot`, `null` — шаг без экрана |
| `claims` | `items: [{t, label, level, src}]` | утверждения; `label`: `fact`, `inference`, `limit`, `pattern`; `level`: 1–5 |
| `table` | `head`, `rows`, `fold`, `filter` | таблица; `fold` — подпись свёрнутой таблицы; `filter: [{col, label, kind}]` — поиск и фильтры по колонкам, `kind`: `select` или `chips` |
| `cards` | `items: [{id, t, q, level, meta, tags, blocks}]`, `filters`, `placeholder` | библиотека с поиском и фильтрами; на карточку ведёт `#c-<id>`; один блок на атлас |
| `prio` | пишет `to-stage.py` | таблица приоритетов: правка в строке, фильтры, подробности; один блок на атлас |
| `prices` | `rows: [[имя, в месяц, за год, оговорка]]`, `band`, `bandLabel`, `monLabel`, `annLabel` | график цен |
| `stack` | `t`, `items: [{t, n, c}]` | полоса долей; `c`: `ok`, `bad`, `warn`, `none`, `accent`, `l0`, `l2`, `l4`, `sunk` |
| `link` | `t`, `url` или `path`, `note`, `final` | материал вне атласа |

Ячейка таблицы — строка, `{"t": "Опровергнуто", "tone": "bad"}` (`ok`, `bad`, `warn`, `none`), `{"t": "●", "tip": "подсказка"}` или `{"level": 2}`.
В тексте работают `**жирный**`, `*курсив*` и ссылки `[текст](https://…)`, другая разметка показывается как текст.

`link` без `final` — временная пометка: материал лежит в другом месте и ещё не перенесён, раздел попадёт в «Что не сделано». С
`"final": true` — итог этого раздела живёт там и раздел считается заполненным (таблица приоритетов).

## Статус этапа

| Статус | Когда |
|---|---|
| Не начат | нет ни материала, ни выводов |
| В работе | заполнена часть разделов, есть только ссылки или нет выводов |
| Ждёт подтверждения | все разделы и выводы есть, `confirmed` нет |
| Готов | всё есть и стоит `confirmed` |
| Пропущен | стоит `skip` |
