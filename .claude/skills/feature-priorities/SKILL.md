# /feature-priorities

Прочитай метод `~/Desktop/Studio/modules/product/prompts/feature-prioritization.md` (Studio — корень воркспейса,
папка с `modules/`; из проекта в `projects/<slug>/` это `../../`) и выполни в текущем проекте.

Ресурсы этого скилла (пути от папки скилла):
- `assets/template.html` — страница: корзины, фильтры, поиск, «Подробнее», правки приоритета и комментариев в базе
  артефакта (значения из базы проверяются по своим ключам). Руками не править — данные идут через сборщик.
- `scripts/build.py <папка-данных> [выход.html]` — проверяет данные и собирает страницу.
- `scripts/to-stage.py <папка-данных> <stages/priorities.json>` — переносит таблицу и подробности в атлас исследования.
- `references/data-format.md` — формат `config.json`, `features.json`, `refs.json`, `jobs.json`, `detail/*.json`.
- `references/detail-brief.md` — бриф агентам, которые пишут разбор конкурентов по группам фич.

Дополняешь уже опубликованную таблицу — сначала прочитай правки пользователя из базы артефакта (`ArtifactData list`
по коллекции из `config.collection`), потом меняй данные и пересобирай тем же путём файла.
