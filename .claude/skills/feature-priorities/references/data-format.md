# Формат данных для build.py

Папка данных:

```
priorities/
├── config.json
├── features.json
├── refs.json      (необязательно)
├── jobs.json      (необязательно)
└── detail/
    ├── A.json     (любые имена, сколько угодно файлов)
    └── B.json
```

## config.json

```json
{
  "title": "Приоритеты фич Acme",
  "eyebrow": "Acme · редизайн · 05.11.2026",
  "heading": "Приоритеты фич",
  "ledeHtml": "Что есть сейчас и что вынесли из ресёрча — в одной таблице. Приоритет — предложение; меняйте его в строке, правки сохраняются для всех. Доказательства — в <a href=\"https://…\" target=\"_blank\" rel=\"noopener\">атласе ресёрча</a>.",
  "product": "Acme",
  "collection": "prio",
  "decideLabel": "Решение за владельцем",
  "refsUrl": "https://claude.ai/artifact/…",
  "areaLabel": "Фаза",
  "areaAll": "Все фазы",
  "areaGroupBy": "фазе",
  "buckets": [
    {"key": "p0", "label": "P0 · ядро", "short": "Проектируем первым"},
    {"key": "p1", "label": "P1 · после ядра", "short": "В первую версию после ядра"},
    {"key": "p2", "label": "P2 · позже", "short": "Держим или откладываем"},
    {"key": "no", "label": "Не делаем", "short": "Отвергнуто или за периметром"}
  ],
  "areas": {"0": "0 · Подключение", "1": "1 · Входящее", "X": "Инфраструктура и периметр"},
  "how": [
    [["P0 · ядро", "Критерий…"], ["P1 · после ядра", "…"], ["P2 · позже", "…"], ["Не делаем", "…"]],
    [["Сейчас", "Есть / Частично / Сломано / Нет — по коду на <дата>"], ["Из ресёрча", "Уровни L1–L5…"], ["Конкуренты", "«Никто» — возможное отличие"]]
  ]
}
```

- `ledeHtml` — единственное поле с HTML (пишет автор таблицы, не пользователи). Ссылки — с `target="_blank" rel="noopener"`.
- `refsUrl` — страница, где источники `refs` открываются по якорю `#id`. Пусто — ссылки не кликаются.
- `collection` — имя коллекции в базе артефакта для правок. Менять только для новой таблицы.
- `how` — колонки блока «Как раскладывали»: массив колонок, в колонке пары [термин, пояснение].
- Корзин может быть другое число, но ключи (`key`) после публикации не менять: правки в базе привязаны к ним.

## features.json

```json
[
  {"id": "P01", "area": "0", "name": "Подключение Gmail (только чтение)", "jobs": "0a",
   "now": "part", "nowNote": "Работает локально; на проде доступ не настроен",
   "research": "Почта — первый канал в выбранном сегменте", "refs": ["b7"],
   "comp": "Superhuman, Moxie", "prio": "p0", "why": "Без канала нет продукта", "decide": false}
]
```

- `now`: `have` | `part` | `broken` | `none`.
- `jobs`: коды через запятую или «—»; если есть `jobs.json`, каждый код должен быть в нём.
- `refs`: id из `refs.json`.
- `comp` — запасной текст; если у фичи есть подробности, колонка строится из имён конкурентов в них.

## refs.json, jobs.json

```json
{"b7": ["Глубокий анализ 21 конкурента", 2], "c1": ["Поведенческие паттерны на корпусе", 4]}
```
```json
{"0a": ["Когда продукт просит доступ к почте, я хочу понимать, что он прочитает, чтобы решиться подключить", "тревога"]}
```

Уровень источника: 1–5 (L1 мнение/синтетика … L5 реальные пользователи), 0 — без уровня.
