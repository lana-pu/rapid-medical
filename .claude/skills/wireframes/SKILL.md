# /wireframes

Метод — `~/Desktop/Studio/modules/design/prompts/wireframes.md` (Studio — корень воркспейса, папка с `modules/`; из
проекта в `projects/<slug>/` это `../../`). Прочитай и выполни в текущем проекте.

Ресурсы этого скилла (пути от папки скилла):
- `assets/kit.js`, `assets/kit.css` — общий набор: компоненты, отрисовка доски, прототипа и библиотеки. Правится для всех
  проектов сразу; новый общий компонент — сюда, с `doc`, `props` и примером.
- `assets/template.html` — оболочка страницы. Руками не править.
- `scripts/build.py <flow.json> <out.html> [--pack pack.js …]` — проверяет флоу (id, переходы, компоненты, недостижимые
  экраны) и собирает одну самодостаточную страницу. `--library <out.html>` — только библиотека.
- `references/flow-format.md` — формат флоу, общие свойства узлов, пак компонентов проекта.

Флоу живут в проекте: `docs/flows/<slug>.json` (+ `docs/flows/pack.js`, если нужны свои компоненты). Собранная страница —
артефакт; публиковать **тем же путём файла**, чтобы ссылка не менялась.
