01

Principles & Techniques

How the direction is built

Principles

The device is the subject. Everything else is a neutral, exact frame around it.

Techniques

What the direction is drawn with, and what it leaves out.

Core

Product photography

Studio-lit devices on a flat neutral ground. Macro detail and true scale; no props, no scenes.

Core

Technical drawings

Line drawings with dimensions and numbered callouts show how a device is built and used.

Core

Flat color

Solid fields of grey, black and white with hairline rules. One accent color, one element per screen.

R
Core

Type as layout

Very large, tight grotesk headlines set the composition; data and labels in monospace.

Sparingly

3D renders

Only true-to-product CAD renders, lit like photography. No abstract or symbolic forms.

Not used

Gradients, glow & glass

No atmospheric color, blur, particles or frosted panels. That language belongs to Directions 01 and 02.
