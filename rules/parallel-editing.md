# Параллельная работа — не забирать чужие правки

Владелица правит файлы в IDE одновременно с AI, иногда параллельно работает другая сессия AI
(со своими коммитами).

- Перед коммитом: `git status --short` и `git diff --cached --name-only`; всё, что не твоё, —
  `git restore --staged`. Ничего не стейджить заранее.
- Запомни `git rev-parse HEAD` в начале и проверь перед/после коммита: если HEAD ушёл и твои файлы уже
  закоммичены чужим коммитом — не пересоздавай.
- Твои 1–2 строки внутри чужой большой правки → коммить только чисто отделимые файлы или свои ханки
  (`git diff -U3 -- <file>` → оставить свои ханки → `git apply --cached --recount`).
- `docs/memory/state.md` и session-файлы владелица может вести сама — не перезаписывать посреди правки,
  дописывать.
