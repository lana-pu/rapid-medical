# rules/ — универсальные правила воркспейса

Действуют во всех проектах. Правила конкретного проекта — в его `docs/rules/` (там только то, что
отличается или добавляется; общие не копировать).

| Когда | Файл |
|---|---|
| UI / страницы / виджеты — всё через компоненты, без хардкода | `ui-components-first.md` |
| DESIGN.md, токены, новые цвета или шрифты | `design-system-first.md` |
| Правка экрана или поведения — спека первой | `spec-first.md` |
| Перед «готово» / коммитом — что проверить | `verification.md` |
| Завершил шаг → коммит, push-политика | `commits.md` |
| Правки владелицы или другой сессии параллельно | `parallel-editing.md` |
| Старт, ход и конец сессии — память | `session-continuity.md` |
| Запуск dev-сервера, Playwright, повторные прогоны | `process-hygiene.md` |
| Что блокируют и о чём напоминают хуки | `hooks-guardrails.md` |
| `NOT` / `notIn` над nullable-полем в запросах | `sql-nullable-not.md` |
| Создал промт или правило в библиотеке | `module-indexation.md` |
