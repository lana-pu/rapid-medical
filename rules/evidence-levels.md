# Доказательность — уровни и метки утверждений

Действует на весь ресёрч и всё, что из него следует (атлас, таблица приоритетов, спека). Цель одна: аккуратная
таблица не должна выглядеть надёжнее данных, на которых стоит.

## Уровни источника

| Уровень | Что это |
|---|---|
| **L1** | мнение, deep-research без проверяемых источников, синтетика (AI-персоны, AI-интервью) |
| **L2** | первичные источники (страницы вендоров, тарифы), эвристический аудит, малые замеры (n < 20) |
| **L3** | замер на своих данных (один пользователь или команда) |
| **L4** | внешние реальные данные в масштабе (корпус, логи, рынок) |
| **L5** | реальные целевые пользователи (интервью, анкета, пилот) |

- Уровень вывода — по самому слабому звену, а не по самому сильному.
- Работа агента сама по себе не поднимает уровень: найденное в поиске и неперепроверенное — L1; проверенное на
  странице вендора — L2. L5 агент получить не может: только люди.
- L1 не цитировать как факт и не ставить единственным основанием для P0.

## Метки утверждений

| Метка | Значит |
|---|---|
| **Подтверждено** | внутреннее: свои данные, код, замер, слова представителя компании; источник можно открыть |
| **Внешний контекст** | подтверждено внешним источником: рынок, корпус, отчёт, страница вендора. Не выдавать за данные компании |
| **Вводная проекта** | дано как условие: решение владельца, бриф, договорённость. Это не проверенный факт |
| **Вывод** | наше рассуждение поверх источников; другой исследователь мог бы сделать другой |
| **Ограничение** | что мешает обобщать: выборка, регион, дата, кто писал источник |
| **Паттерн** | решение из другого продукта или области, которое можно перенести |

В конце каждого раздела ресёрча — «Выводы для решения»: что из этого меняет решение. Не подтвердилось — убрать, а не
смягчать формулировку. Не нашли данных — так и написать: «не нашли» не значит «нет».
