# Security checklist — Rapid Medical

Растущий список «что проверять» в этом проекте (эталон A–N — `modules/development/prompts/security-check-template.md`).
Дополнять после каждого аудита. Отчёты — `docs/audits/`.

## Вход и роли
- [ ] Каждое экспортируемое действие в `"use server"` файлах и каждое действие в страницах начинается с
      `requireUser / requireEditor / requireAdmin / requireSignedIn` (скрипт из аудита 2026-11-13).
- [ ] `/api/admin/*` пускает только `isReady(session)` (пароль + 2FA настроена и пройдена).
- [ ] Попытки пароля и кода второго шага ограничены (`login_attempts`).
- [ ] Роли проверяются на сервере: `requireAdmin`, `canDesign`, `mayEditGroup` / `mayEditOnPage`.
- [ ] Приглашение и сброс: одноразовые, срок, разные назначения (`purpose`), сброс админом закрывает сессии.

## Публикация
- [ ] Сохранение (форма, страница, медиатека, restore) никогда не публикует; публикует только Publish.
- [ ] Черновики ограниченных групп настроек публикуются только с проверкой «изменились лишь тексты» в транзакции.

## Ввод и вывод
- [ ] Сырой HTML выводится только через `safeHtml` (`sanitize-html`, белый список).
- [ ] Адреса в блоках, меню, вкладках — путь `/…` (не `//`, не `\`) или `https://`.
- [ ] Переадресации по параметру (`next`, `redirect`, `back`) — только через `safeLocalPath`.
- [ ] Значения настроек, попадающие в скрипты (GA, UserWay), проверяются по формату.

## Загрузки
- [ ] Тип файла — по содержимому (первые байты), расширение — от типа; SVG без скриптов; `/uploads` с `nosniff`.

## Секреты и окружение
- [ ] `AUTH_SECRET` обязателен (≥ 32 символов); `CRON_SECRET` обязателен в проде.
- [ ] Без SMTP ссылки приглашений/сброса не уходят в логи прода.
- [ ] Демо-экспорт — только с тестовой базы (проверка встроена).

## Миграции
- [ ] Новое значение enum не используется в миграциях той же цепочки (на чистой базе они в одной транзакции).
