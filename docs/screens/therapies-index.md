# Экран: Список терапий `/{region}/therapies`

Код: `src/app/(site)/[seg]/therapies/page.tsx`. Страница хранится списком блоков (`site_pages`, key `therapies`, по
региону, ADR-007); секции терапий — блоки Columns · `cards` с источником `therapyGroup`, по одному на направление.
Без записи те же блоки собирает `therapiesToBlocks()` (`src/blocks/from-settings.ts`); правило секций —
`overviewSections()`. Данные: настройки `therapies:{region}`, записи `solutions` региона, публикации региона (как на
Evidence). Раскладка — `docs/DESIGN.md → Обзор терапий` (решение 2026-11-15, ветка `site-redesign`).

## Блоки
| Порядок | Блок · вариант | Из полей | Условие |
|---|---|---|---|
| 1 | Hero · `bannerCompact` | название региона, `title`, `intro`, `note`, `heroVideoUrl` | всегда |
| 2 | Columns · `cards`, по направлениям (Ischemic stroke → Hemorrhagic stroke → Access → без группы) | записи `solutions`; карточка — см. ниже | есть терапии |
| 3 | Call to action · `light` | `closingTitle`, `closingBody`; кнопка «Contact us» → `/contact-us?region={region}` | всегда |

**Группы:** у направления с 2+ терапиями — заголовок группы, на карточке только продукт. Направления с одной терапией
заголовка не получают: их карточки стоят одним рядом (на месте первого такого направления), направление — в подписи
карточки («Ischemic stroke · TIGERTRIEVER™»). В Americas так все три; в Europe и Asia & Pacific — заголовки у Ischemic
и Hemorrhagic, Access — отдельным рядом.

**Карточка:** подпись (направление · продукт или только продукт), название (`navLabel`, ссылка), подзаголовок
(`heroTitle`), строка-доказательство (`proofPoint`, если заполнена — после MLR), «Explore →» на терапию и «N
publications →» на Evidence с вкладкой продукта (`/{region}/evidence#{product}`) — N считается так же, как список на
Evidence (семейство с подпродуктами без своей вкладки); у продукта без публикаций в регионе ссылки нет. Две терапии
одного продукта (Aneurysm и Vasospasm — COMANECI™) ведут на одну вкладку с одним числом. Фото устройства 4:3 — по
решению, когда клиент пришлёт рендеры (BACKLOG №22); до тех пор карточки без картинки.

Плашки «{терапия} is not available in {регион}» нет (решение 2026-11-15): ссылок на терапии, которых нет в регионе, на
сайте не бывает; переключатель региона с такой терапии ведёт сюда без пояснений, `?missing=` не используется. Старые
адреса Duda `/us/mvo` и `/us/vasospasm` ведут сюда (`/us/therapies`, миграция `0025`), а не на несуществующую страницу.

Решение 2026-11-10: страница необязательная — обзор для тех, кто не знает линейку. Собирается из записей терапий;
тексты направлений в настройках (`blocks[]`) больше не показываются, но не удалены. Ссылки «change» в hero нет — регион
меняется в шапке.

## Проход по юзабилити 2026-11-13
- `?missing={slug}` с плашкой «not available» — убрано 2026-11-15 (см. выше).
