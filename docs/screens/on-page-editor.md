# Экран: редактор страницы («Edit site»)

Основа: ADR-006 (правка на странице, как в Webflow), ADR-007 (страница = список блоков), бриф `docs/briefs/page-editor.md`,
флоу `docs/flows/site-editor.json`. Статус: **в работе с 2026-11-12** — раздел «Сделано» внизу.

Код: `src/components/editor/` (клиент, грузится только в режиме редактора), `src/blocks/stored.ts` (хранение и показ блоков),
`src/admin/inline.ts` (правка поля), `src/admin/blocks-actions.ts` (операции над секциями, версии, история),
`src/lib/editing.ts`, `src/app/api/editor/route.ts`. Демо: `src/components/editor/demo-store.ts`.

## Доступ и вход
- Вход: список страниц `/admin/editor` (клик по странице), сайдбар «Edit site ✎», «Edit on page ✎» в записи →
  `GET /api/editor?on=1&redirect=/path`.
- Нужна сессия с пройденной 2FA (любая роль). Без сессии → `/admin/login?next=…`, после входа редактор включается сам.
  Выход: `/api/editor?off=1`.
- Режим активен, когда одновременно: Next draft mode + cookie `rm_edit=1` + валидная сессия. В режиме редактора
  GA и UserWay не грузятся, баннер preview скрыт.

## Какие страницы
| Страница | Хранение | Секции |
|---|---|---|
| Терапия `/{region}/therapies/{slug}` | `solutions.blocks` | добавлять, двигать, копировать, удалять |
| Текстовая и лендинг `/{region}/{slug}`, `/{slug}` | `pages.blocks` | то же |
| Home, About, Careers, Evidence, обзор терапий | `site_pages.blocks` | то же |
| News & Events, Webinars, Open positions, вакансия, событие, Contact, выбор региона | собираются из коллекций | фиксированы; тексты записей правятся на месте, как раньше |

## Два режима: страница и разметка (решение владелицы 2026-11-14)
Редактор открывается **в режиме страницы (Content)** — страница выглядит так, как её увидят посетители: без рамок,
пунктиров, подписей секций и кнопок «+ Add section». Работа — как в Word: навёл, кликнул, поменял.
| Content (по умолчанию, при каждом открытии страницы) | Layout (**Tools ▾ → Arrange sections**) |
|---|---|
| Под курсором — лёгкая подложка только на редактируемом элементе (текст, кнопка, картинка) и подходящий курсор; без наведения — ничего | Всё, что ниже в «Секции»: рамки секций, выделение, панель секции, «+ Add section», вкладки |
| Клик по тексту — правка на месте; по кнопке, картинке, rich-тексту — боковая панель (как ниже) | То же, плюс выбор секции кликом по пустому месту |
| Навёл на секцию — у её левого края кнопка **Hide** (скрыть на сайте); у закреплённых блоков (Indications) её нет | Hide / Show — и в панели выделенной секции |
| Скрытая секция — полоска «Hidden on the site · {секция}» с кнопкой **Show** | то же |
Режим Layout доступен всем ролям (ADR-006: редактор собирает страницы из пресетов); выбор варианта секции — по-прежнему
только дизайнер и админ. Выключается тем же пунктом. Новое открытие страницы — снова Content.
Страницы-каталоги (News & Events, Webinars, вакансии, событие, Contact, выбор региона) не хранятся списком секций:
у них только правка текстов и картинок, без Hide и без Layout.

## Скрытые секции
- Hide — секция остаётся на странице, но на сайте её нет **после Publish** (как любая правка, это черновик). Show
  возвращает. Undo отменяет. Скрытие у каждой страницы своё, значит и у каждого региона своё.
- Можно скрыть секцию страницы и секцию внутри вкладки Product details. Нельзя — закреплённые (Indications and references).
- В редакторе скрытая секция свёрнута в полоску «Hidden on the site · {секция}» с кнопкой Show; в Preview её нет.
- Review changes и История: «Hid section {секция}», «Showed section {секция}».
- Данные: `hidden: true` у блока в `blocks` (у секции во вкладке — у элемента вкладки); посетителям такие блоки не
  отдаются вовсе. Операция `hide` в `src/blocks/ops.ts`.

## Верхняя панель
Одна строка над страницей (тёмная, страница сдвинута вниз на её высоту):
| Элемент | Поведение |
|---|---|
| ← Pages | в список страниц `/admin/editor` |
| Название страницы · тип | «Large vessel stroke · Therapy page» |
| Меню региона | «Americas ▾»: регионы, где есть эта страница; выбор открывает её там. Нет страницы в регионе — пункт недоступен с подписью «No version». У глобальных страниц меню нет |
| Tools ▾ | **Arrange sections** (вкл/выкл режим Layout), **Compare with…** (выбор другого региона: секции, которые отличаются, обведены рамкой с подписью «Different in {регион}» / «Only here»), **Preview** |
| Статус | «Live», «Live, with unpublished changes», «Draft — not live yet»; при сохранении «Saving…» → «Saved. Not live yet» |
| ↶ Undo · ↷ Redo | Undo отменяет последнее действие в этой сессии (текст, медиа, секция, вкладки); Redo возвращает отменённое. Новое действие очищает Redo. Ctrl/⌘+Z и Ctrl/⌘+Shift+Z вне поля ввода |
| History | панель версий |
| Preview (в Tools) | страница без подсветки, скрытых секций и панелей (как увидит посетитель после Publish); «Back to editing» |
| Publish | есть неопубликованные изменения → окно проверки |
Меньше 768 px: название и статус уходят во второй ряд.

## Правка на месте (оба режима)
| Вид | Поля | Взаимодействие |
|---|---|---|
| text | заголовки, короткие тексты | клик → правка в странице. Enter — сохранить, Esc — отменить, Shift+Enter — перенос строки |
| rich | показания, источники, тела страниц | клик → боковая панель с редактором текста |
| link | подпись + адрес | боковая панель: два поля |
| media | картинка, видео | боковая панель: превью, Replace image / Replace video (медиатека), Remove video, Clear image |
В режиме Content подсвечивается только элемент под курсором; в Layout пунктир показывает всё, что можно поменять.
Шрифт, цвет и размер недоступны.
Сохранение автоматическое. Ошибка → «Not saved: …», значение возвращается.

## Секции (режим Layout)
- Наведение на секцию — тонкая рамка; клик по пустому месту секции (не по тексту) — выделение.
- Панель выделенной секции: название блока, **вариант** (список из реестра блока — только у дизайнера и админа, ADR-006;
  редактор видит название без выбора), ↑ ↓, Copy, Delete.
  Удаление — сразу, с «Undo» в статусе; без confirm.
- «+ Add section» на верхней и нижней границе наведённой или выделенной секции → панель пресетов с поиском: блоки
  по группам, у варианта мини-превью, название и описание. Превью — уменьшенный образец этого варианта из витрины
  `/style-guide` (тот же, что встанет на страницу), без ссылок и кликов; пока образец грузится — серый прямоугольник. Новая секция встаёт в выбранное место с примерным
  текстом, выделена, страница прокручивается к ней, текст сразу правится кликом.
- Пока идёт правка, ссылки на странице не переходят (кнопки — например, вкладки — работают). Перейти по ссылке — в Preview.
- Закреплённые блоки (Indications and references) нельзя удалить, сдвинуть или скопировать; всегда в конце страницы.
  Новая секция «после» них встаёт перед ними.
- Секции со списками из коллекций (новости, публикации, команда, карточки терапий): свои тексты правятся на месте,
  элементы списка — в своих записях (ссылка «Edit items in admin»).
- **Секции внутри вкладок «Product details»** — те же действия, что у секций страницы, внутри открытой вкладки:
  наведение, выделение, вариант, ↑ ↓, Copy, Delete, «+ Add section» на границах. Выделяется самая внутренняя секция под
  курсором; клик по пустому месту вкладки вне её секций выделяет сам блок Product details. Под курсором — только видимая
  вкладка; переключение вкладок работает как у посетителя.
  - Внутрь вкладки добавляются только блоки, которые могут стоять во вкладке (`nestable`: текст, колонки, ключевые
    цифры, схема устройства, таблица спецификаций, кнопки, люди) — панель пресетов показывает только их.
  - Секции под подзаголовком вкладки («Specifications») двигаются и копируются внутри своей группы; новая секция у её
    границы встаёт в группу. Удаление последней секции группы убирает и подзаголовок.
  - Последнюю секцию вкладки удалить нельзя: «A tab keeps at least one section». Вкладки-ссылки секций не имеют.
  - **Сами вкладки**: у выделенного блока Product details в панели кнопка **Tabs** → боковая панель со списком вкладок:
    подпись (сохраняется при уходе из поля), ↑ ↓, Delete, у вкладки-ссылки — адрес; внизу **+ Add tab** (новая вкладка с
    одной секцией Text) и **+ Add link tab** (подпись и адрес: путь на сайте `/…` или `https://…`). Последнюю вкладку
    с содержимым удалить нельзя: «Product details keeps at least one tab with content». Подпись — 1–60 символов.
    Адрес вкладки (`#…` для ссылок с других страниц) делается из подписи и не меняется при переименовании.
    Review changes: «Added tab “X”», «Removed tab “X”», «Renamed tab “A” to “B”», «Moved tabs», «Changed the link of tab “X”».
    В демо правка вкладок недоступна (нужен сервер).
  - Review changes словами: «Added Text in tab “How it works”», «Removed Spec table in tab …», «Changed Text in tab …»,
    «Moved sections in tab …».

## Комментарии (ADR-006: вместо согласования — комментарии на месте, как в Figma)
- В верхней панели **Comment** (число открытых) → панель **Comments** справа и режим комментария: клик по секции открывает
  поле «Comment on {секция}». Кнопка «Comment on the whole page» — без привязки к секции.
- У секции с открытыми комментариями — кружок с числом в правом верхнем углу; клик открывает её ветку в панели.
- Ветка: текст, кто, когда; **Reply**, **Resolve** (закрыть; «Show resolved» показывает закрытые, их можно открыть снова),
  **Delete** — свой комментарий или любой, если ты админ; ветку с чужими ответами удаляет только админ (автору —
  «Others replied to it — resolve it instead»). Текст до 2000 символов, только текст.
- Комментарии не меняют страницу и не ждут Publish; их видят все, кто работает в админке. Секция, которой больше нет,
  — ветка показывается в разделе «Page».
- На главной админки (`admin-home.md`) — «{N} open comments on {страница}» со ссылкой в редактор.
- В демо недоступно (нужен сервер). Данные: таблица `comments` (страница, секция, ответ на, автор, закрыт кем и когда).

## Сохранение
Всё идёт через workflow (ADR-003): опубликованная страница → черновик в `drafts`, посетители видят старую версию до Publish;
неопубликованная → правка на месте. Каждое сохранение — ревизия.
**Одновременная правка:** сохранение несёт версию страницы; если её поменял другой человек —
«This page was changed by {имя}. Reload to see their changes» и кнопка Reload, правка не применяется.

## Публикация
1. Publish → окно «Review changes»: список изменений словами («Changed text in Hero», «Added section Key numbers»,
   «Removed section Video», «Moved section Text», «Changed image in Benefits 2», «Changed variant of Hero»), кто и когда.
   Кнопки Publish now / Keep editing / Discard all changes (с подтверждением).
2. После Publish → окно «Live now»: адрес страницы, «Open live page ↗», «Keep editing».

## История
Панель справа: версии страницы новые сверху — «Published», «Saved», «Restored», кто, когда. «Restore this version» кладёт
версию на страницу черновиком: видно сразу на странице, на сайт — после Publish, отменяется Discard или Undo.
Если восстановленная версия совпадает с опубликованной — черновика нет, статус «Version restored — it is what is
live, nothing to publish», Publish неактивна (расписание публикации, если было, остаётся). UX-прогон 2026-11-14:
раньше статус говорил «unpublished changes», а Review — «No changes to publish».

| Состояние | Что видно |
|---|---|
| Загрузка панели | «Loading…» в статусе |
| Ошибка сети | «Not saved: …», значение возвращается |

## Демо (GitHub Pages)
Без сервера: правки текста и медиа и секции хранятся в `localStorage` этого браузера, операции с секциями
повторяются при загрузке страницы. Сдвиг, копия, удаление — прямо в странице; новая секция копируется из витрины
блоков `/style-guide` (образцы помечены `data-rm-preset`). Копии и новые секции в демо не правятся (образец),
вариант не меняется, History и Compare with… недоступны (нужен сервер), Undo секций перезагружает страницу, Redo — только
для текста и медиа.
Секции внутри вкладок в демо — так же (сдвиг, копия, удаление, добавление образца). Hide / Show в демо — тоже
(секция прячется в странице и сворачивается в полоску).
«View as visitor» прячет панели.
