# Экран: Media library (`/admin/media`)

Основа: флоу админки `docs/flows/admin.json` (экраны media, media-file, media-replace), решение владелицы 2026-11-11
(замена файла — черновиком), BACKLOG «Медиатека: фильтр без alt и массовое заполнение» (C.9/C.10 аудита: 60–80 %
картинок без описания). Код: `src/app/admin/(dashboard)/media/`, `src/components/admin/MediaGrid.tsx`,
`src/admin/media-actions.ts`, `src/lib/media-usage.ts`, `src/app/api/admin/media/route.ts`.

## Список
- Загрузка (кнопка и перетаскивание): картинки, mp4/webm, PDF, до 200 МБ. Картинки → WebP-варианты, видео → постер.
- Поиск по имени и описанию; фильтр типа: All · Pictures · Videos · Documents · **No description (N)** — картинки без alt.
- Карточка: миниатюра, имя, размер, поле описания (сохраняется при уходе из поля), пометка **No description** у картинок
  без alt, copy URL, delete (используемый файл удалить нельзя — список мест).
- Кнопка **Describe pictures (N)** → очередь описаний (ниже).

## Файл (`?id=`)
- Превью, адрес, размер, источник (Duda), **описание** (alt) с сохранением.
- **Used in N places**: страницы и записи со ссылкой в админку; страницы — и ссылкой «Open on page»; место, где файл
  стоит только в черновике, помечено «in unpublished changes». Учитываются черновики записей и настроек; старые тексты
  страниц в настройках (`home`, `about`, `careers`, `evidence`, `therapies:*` — переехали в `site_pages`) не учитываются.
- **Replace everywhere** (если файл где-то стоит): окно замены.

## Замена файла везде
1. Выбрать новый файл: загрузить или взять из медиатеки (того же вида: картинка на картинку, видео на видео, PDF на PDF).
2. «Now / New» рядом; «The new file takes its place in N places. The description stays.»
3. Режим:
   - **Add as unpublished changes** (по умолчанию) — в каждой записи появляется черновик с новым файлом; на сайте — после
     Publish этой страницы (в редакторе или в записи). Настройки (офисы, Home до переноса) — черновик настроек.
   - **Replace and publish now** — только если пользователь может публиковать (согласование выключено или admin/approver);
     иначе вариант недоступен с подписью «Needs approval: publish each page after review».
4. Результат: «Replaced in N places as unpublished changes» и список мест со ссылками. Записи, которые уже открыты
   другим редактором с более свежим черновиком, всё равно получают замену поверх их черновика (замена — точечная, другие
   правки черновика сохраняются).
- Замена точная: меняется адрес файла целиком везде, где он стоит (поля, списки блоков, rich text, списки картинок).
  Варианты и постер берутся у нового файла. Описание: если у нового файла его нет, копируется со старого.
- Старый файл остаётся в медиатеке; удалить его можно, когда он нигде не стоит (в том числе в черновиках — после Publish).
- Каждое изменение — ревизия записи и строка в журнале действий (`media`, «replaced»).

## Очередь описаний (`?describe=1`)
- Картинки без alt, сначала используемые на сайте (у каждой — где стоит), потом неиспользуемые.
- У каждой: большая миниатюра, имя файла, места использования, поле описания и подсказки одним кликом: имя файла
  словами и заголовки мест (например, «Large vessel stroke — Gain active control»). Enter — сохранить и к следующей.
- Счётчик «N left». Пусто → «Every picture has a description».

## Описание на сайте
Описание из медиатеки — основной alt картинки на сайте; если его нет — подпись блока (заголовок, имя человека).
Пустой alt допустим только у декоративных картинок (нет ни описания, ни подписи).

## Права
Загрузка, описание, замена черновиком — любой вошедший с 2FA. Публикация при замене — по правилам Publish.
Удаление — только неиспользуемых файлов.
