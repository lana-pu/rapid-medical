## Что обычно нужно такому сайту (B2B, медтех, мало трафика, ценен каждый лид)
1. **Лиды**: сколько за неделю/месяц, по формам и темам (демо, поддержка, вебинары, карьера), по регионам и странам.
2. **Откуда лиды**: LinkedIn / Google / прямые / конгрессы (UTM) и **какая страница привела** (терапия → «Request a demo»).
3. **Посещаемость**: визиты, страницы, страны, источники — без деталей уровня маркетологов, тренды.
4. **Материалы**: какие PDF и исследования открывают, какие вебинары запрашивают.
5. **Здоровье**: битые ссылки, медленные страницы, картинки без описания (уже есть).

## Как сделать — три пути
| | Как | Плюсы | Минусы |
|---|---|---|---|
| **A. GA4 в админке** | Google Analytics Data API (сервисный аккаунт в их GA) → плитки и графики на дашборде | одна правда с маркетингом, история с Duda | нужен доступ к GA и cookie consent: в ЕС без согласия данных нет; пороги и выборки GA; нет связи с конкретной заявкой |
| **B. Своя аналитика без cookie** | счётчик просмотров в нашей базе (страница, регион, источник/UTM, страна по заголовку; без IP и cookie), скачивания PDF через наш адрес, плюс уже собранное в заявках | полные данные без баннера согласия, связь «визит → заявка», ничего стороннего, бесплатно | пишем и поддерживаем сами; истории до запуска нет; фильтр ботов по простым правилам |
| **C. Plausible / Umami** | готовая приватная аналитика (облако ~9–19 $/мес или своя), её виджеты/API в админку | готовые графики, без cookie | ещё один сервис и счёт; заявки — всё равно у нас |

## Предложение
**Гибрид B + наши заявки, GA4 оставить маркетингу.**
- **Сразу, без нового трекинга** — раздел «Leads» на дашборде из того, что уже пишется в заявки: лиды по неделям,
  по формам и темам, по регионам, **по источнику** (LinkedIn, Google, прямые, кампании) и **по странице, которая
  привела**; запросы вебинаров по вебинарам.
- **Следом** — свой счётчик без cookie: посещаемость, топ страниц, страны, источники; скачивания PDF и открытия
  исследований. В админке — «Analytics» с периодом (7 / 30 / 90 дней) и сравнением с прошлым периодом, понятными
  словами («LinkedIn привёл 12 человек и 2 заявки»).
- GA4 и Search Console — у маркетинга как были; ссылки на них из админки.
