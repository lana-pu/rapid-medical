## Среднее ⚠️

### N.2 — тесты и `seed --reset` не проверяют, что база тестовая
- **Где:** `tests/e2e/global-setup.ts`, `scripts/seed.ts --reset`.
- **Что:** берут `DATABASE_URL` из `.env` и выполняют `TRUNCATE` контента, чистят журнал и сессии, создают
  администратора `e2e@rapid-medical.com` с паролем и ключом 2FA, **которые лежат в публичном репозитории**
  (`tests/e2e/helpers.ts`). Запуск с адресом боевой базы в `.env` (например, чтобы прогнать миграции) — потеря контента
  и готовая учётка администратора для любого, кто читал репозиторий.
- **Предложение:** отказ, если хост базы не локальный (`localhost`, `127.0.0.1`, `::1`, сервис `db` в Docker) и это не
  CI; явный обход — переменная окружения.

### J.2 — секрет cron сравнивается обычным `!==`
- **Где:** `src/app/api/cron/publish/route.ts`. Риск низкий (подбор по времени ответа через сеть), исправление —
  `crypto.timingSafeEqual`.

### Открыто с прошлого раза
- **H.1** CSP для сайта и админки (nonce для скриптов Next и GA) — вместе с подключением Vercel.
- **E.2** минимальная длина пароля 10 (эталон для админов — 16) — решение владелицы.
- **Права:** удаление, снятие с сайта, Discard, Schedule, Restore — без проверки роли (модель прав, BACKLOG №5).
