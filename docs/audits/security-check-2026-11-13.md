## Критично 🔴

### E.1 — перебор кода второго шага не ограничен
- **Где:** `src/app/admin/login/2fa/page.tsx` → `verify`
- **Что:** после верного пароля код вводится сколько угодно раз; лимит есть только на пароль.
- **Атака:** узнав пароль, перебирать 6-значные коды; в среднем подбор за часы.
- **Чинить:** считать неудачные коды (`login_attempts`, ключ `totp:{userId}`); после 5 за 15 мин — сессия закрывается,
  снова пароль (он сам ограничен).

### C.1 / F — хранимый XSS через загрузку файла
- **Где:** `src/app/api/admin/upload/route.ts`, `src/lib/media.ts`, `src/lib/images.ts:33`, `src/lib/storage.ts:16`
- **Что:** тип берётся из `file.type` (его присылает браузер), расширение — из имени файла; оригинал сохраняется до
  обработки картинки. SVG разрешён. `/uploads/*` раздаётся без `nosniff` (proxy их не трогает).
- **Атака:** вошедший в админку (или укравший сессию) загружает `x.html` с типом `image/png` или SVG со `<script>` →
  файл на нашем домене выполняет скрипт у того, кто его откроет (в том числе админа).
- **Чинить:** тип — по первым байтам файла (PNG, JPEG, WebP, GIF, PDF, MP4, WebM), расширение — от найденного типа;
  SVG — только без скриптов, обработчиков, `foreignObject` и `javascript:`; на `/uploads/*` — `nosniff` и
  `Content-Security-Policy: sandbox` для SVG.

### R.1 — открытые переадресации
- **Где:** `src/app/api/preview/route.ts:14` (`?exit=1&redirect=` — без проверки); `src/app/api/editor/route.ts:13` и
  `src/lib/editing.ts:52` (`/\evil.com` проходит проверку «начинается с /, не с //»); `src/app/admin/login/page.tsx:13`,
  `login/2fa/page.tsx:15` (`next` без проверки, если уже вошли).
- **Атака:** ссылка на наш домен уводит на фишинговую копию входа.
- **Чинить:** одна функция `safeLocalPath` (только путь на сайте: `/`, без `//`, `\`, управляющих символов) во всех местах.

### G.1 — без `AUTH_SECRET` ссылки предпросмотра можно подделать
- **Где:** `src/lib/preview.ts:5` — `process.env.AUTH_SECRET!`
- **Что:** если переменную забудут задать, JWT подписывается строкой «undefined».
- **Чинить:** без секрета (или короче 32 символов) — ошибка, а не тихая подпись.
