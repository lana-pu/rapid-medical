# Коммиты и push — Rapid Medical

Общие правила — `../../../../rules/commits.md` (атомарно, без `git add -A`, спека в том же коммите).
Здесь — что отличается в этом проекте.

## Формат сообщений
Как в истории репозитория: короткая фраза на английском, что сделано («Admin block D: server sessions,
login throttling…»). Документация (`docs/`) — тоже по-английски в сообщении, содержимое docs — по-русски.

## Push-политика
- **Сейчас (2026-11-05) Vercel не подключён:** push в `main` запускает только CI (GitHub Actions),
  деплоя нет. Коммитить — сразу после шага; docs можно пушить сразу, код — после зелёных
  `tsc` / `lint` / `npm test`.
- **После подключения Vercel** push в `main` = деплой: только после зелёных `npm run build` и `npm test`
  и с явного согласия владелицы. Обновить этот пункт в тот же день, что и подключение.
- Крупная работа — в ветке, затем PR/merge в `main` осознанно.
- Ветка `gh-pages` — только через `npm run demo:export` (статическое демо), руками не править.
- Сайт и инструмент Tigertriever живут в одном репозитории намеренно (ADR-005).

## Перед коммитом кода
`npx tsc --noEmit` и `npm run lint`; для логики админки и workflow — `npm test` (Vitest);
для публичных страниц и редактора — по возможности `npm run test:e2e` (нужна scratch-БД).
