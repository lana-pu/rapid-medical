## Решения владелицы (2026-11-10)

- **Аналитика — Б + Г.** Сайт сам шлёт в GA4 событие об успешной заявке (форма, тема), клик по email, скачивание
  PDF, переход с обзора терапий на продукт; плюс страница отправки и источник визита пишутся в саму заявку
  (видно в админке, не зависит от GA и согласия на cookie). Варианты «GA угадывает сам» и Tag Manager отклонены.
  Почему у клиента не было конверсий: цели не отмечены в GA4, считались начатые, а не отправленные формы, и три
  домена теряли источник на переходе www → поддомен.
- **Регион.** На Duda обзор терапий был обязательной первой страницей поддомена — отсюда «гейт». Теперь регион по
  IP применяется сразу, переключатель в шапке, выбор региона — только если страна не определилась. Обзор терапий
  остаётся необязательным (для инвесторов и первого визита), собирается из записей терапий. Это совпадает с
  Fix List C.2 и советом Emily «keep and rebuild». Подробно — `spec.md → Регионы и URL`.

## Предложения (на подтверждение владелицы, кода не трогали)

1. **События GA4 из сайта:** успешная отправка формы (`generate_lead` с параметром `form` = contact / webinar /
   careers / тема), клик по `mailto:`, скачивание PDF, переход с лендинга терапий на продукт (клиент просил мерить
   «роутер»). Key event отмечает маркетинг в GA4. Зависит от решения по cookie consent (№10).
2. **Гейт на первом визите:** если регион по IP известен, «Therapies» и «Evidence» в шапке и 301 с `/our-solutions`,
   `/evidence` ведут сразу в этот регион; баннер и переключатель остаются. Нет IP-региона — остаётся выбор.
   Нужна правка `spec.md → Регионы и URL` и `screens/choose-your-location.md`.
3. **Редиректы из аудита:** `/welcome` → `/`, `/{region}/contactus` и `/{region}/contact-us` → `/contact-us`.
   Попутно убрать `U+200B` из `pages.json:25`.
4. **JSON-LD:** `Organization` в layout, `MedicalDevice` на странице продукта (из полей продукта), `Event` — когда
   появится тип мероприятий (№18).
5. **Новости с телом записи** — после ответа клиента, будут ли они писать релизы на сайте.

Цифры и выводы аудита (боты, внутренний трафик, доли каналов) — данные клиента, не наши замеры.
