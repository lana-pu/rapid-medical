# Инвентарь секций сайта — состав коллекции блоков

2026-11-07. Основа для коллекции сборных блоков (ADR-006: правка на странице, блоки двигаются и добавляются из пресетов).

**Как собрано.** Демо `gh-pages` на `ea4ae75`: 52 публичные страницы (без трёх редиректов `/us`, `/ous`, `/apac` и 404),
134 секции верхнего уровня. Для каждой секции записаны структура (заголовки, картинки, видео, таблицы, вкладки, формы),
поля данных из атрибутов `data-e` и скриншот. Классификация автоматическая, затем проверена глазами по скриншотам.
Скрипты лежат во временной папке сессии, в репозиторий не входят. Наглядный каталог со скриншотами каждого блока и
варианта (приватная ссылка): https://claude.ai/artifact/DvtThriAGQngpkvNTeddy5

## Главное

- **Уникальных секций на сайте 30 типов, но по сути блоков около 20.** Многие типы — один и тот же блок в разном оформлении
  или с разными данными.
- **Страницы терапий (13 страниц, 3 региона) — основной потребитель блоков.** Шесть типов секций повторяются на каждой.
- **Половина блоков не вынесена в компоненты:** split-hero, ряд «текст + медиа», вводный текст, видео-полоса,
  «Questions?», регуляторный блок, шаги, сетка команды, карточки публикаций и вебинаров написаны прямо в шаблонах страниц.
- **Один и тот же блок сделан по-разному.** «Questions?» есть тёмный (10 страниц) и светлый (3 страницы), плюс та же
  мысль внутри секции карты и на главной. Hero — три разные реализации.
- **Содержимое страниц лежит в трёх местах:** настройки сайта (главная, About, Careers, Evidence, список терапий),
  записи терапий, записи `pages`. Для блочной модели все они станут страницами из блоков.
- **Регионы отличаются блоками, а не только текстом.** APAC Large vessel stroke использует split-hero с картинкой и
  вводный блок с картинкой, а US и OUS — hero с видео. На APAC Evidence нет блока Featured publications.

## Предлагаемый состав коллекции

Принцип: один блок — одно назначение, отличия оформления — варианты блока, а не отдельные блоки.

### Блоки контента: их добавляет редактор из пресетов

| Блок | Варианты | Что закрывает из инвентаря |
|---|---|---|
| **Hero** | тёмный с видео или картинкой · split с картинкой · только заголовок | 24 страницы, три реализации сводятся к одной |
| **Text** | фон светлый, серый, тёмный · по центру, слева · с картинкой под текстом | вводный текст, About, тёмный текст главной |
| **Text and media** | картинка слева, справа · видео · вторая картинка · кнопки · цифры | 37 рядов терапий, список направлений терапии, «проблема» на главной |
| **Key numbers** | круги · строка с иконками · один бейдж | круги в рядах, счётчики главной, «85+» Evidence |
| **Columns** | с картинкой или видео · только текст · нумерованные шаги | How it works, Principles, список преимуществ |
| **Video** | на тёмном фоне · YouTube или файл | видео-полоса LVO |
| **Call to action** | тёмная полоса · светлая · с картой | «Questions?» ×13, финал About, кнопка на главной |
| **Rich text** | обычный · мелкий для сносок | 17 длинных страниц, биографии |
| **Product details** | вкладки или аккордеон, внутри любые блоки | вкладки на 13 страницах терапий |
| **Device diagram** | схема с подписями | 13 страниц |
| **Spec table** | — | 13 страниц |
| **Gallery** | картинки с цитатами | Careers |

### Блоки списков: показывают записи из коллекции

Редактор выбирает, что показывать, а сами записи правит в списке.

| Блок | Варианты |
|---|---|
| **News** | карточки (главная) · карусель · лента по годам |
| **Publications** | подборка с каруселью · карточки · по продуктам |
| **People** | сетка команды · список врачей с вебинарами |
| **Webinars** | карточки |

### Системные блоки: ставит дизайнер или админ

| Блок | Почему системный |
|---|---|
| **Indications and references** | Регуляторный текст: на месте в конце страницы, не удаляется редактором |
| **Form** | Получатели и поля связаны с настройками и интеграциями |
| **Offices and map** | Данные из настроек контактов |
| **Region chooser** | Логика регионов |

Итого: 12 блоков контента, 4 блока списков, 4 системных. Меню и футер остаются общими для сайта.

## Что заметили попутно

- Заголовки рядов на страницах терапий разрезаны: eyebrow «Gain active» и H2 «control». Так было на Duda. Для чтения и
  для поиска заголовок второго уровня — одно слово. Решать при дизайне блока **Text and media**.

## Что дальше

1. Подтвердить состав коллекции (владелица).
2. Описать каждый блок в `docs/DESIGN.md`: назначение, поля, варианты, что может редактор и что дизайнер.
3. Вынести блоки в компоненты `src/components/site/blocks/`, начиная с тех, что сейчас в шаблонах.
4. Модель данных: страница как упорядоченный список блоков. Перенос настроек сайта, записей терапий и `pages` в неё.
