# Медиатека: одна копия каждого файла (2026-11-18)

Задача владелицы: из-за сборки с Duda много копий — одинаковые картинки и видео под разными именами, иногда чуть
обрезанные или пережатые; оставить по одной и расставить правильно по регионам. Ветка `materials`.

## Итог
- **246 → 171 файл в медиатеке; удалено 75 копий и 217 файлов на диске** (сами копии, их варианты, обложки видео и
  страницы PDF), **~132 МБ**; `public/uploads` 379 → 253 МБ (в истории git файлы остаются).
- 49 групп: 38 — побайтовые копии (одна картинка на каждом из трёх сайтов Duda — US, OUS, APAC), 11 — та же картинка
  или видео в другом размере, формате или сжатии.
- Ссылки на копии заменены ссылкой на оригинал во всех текстовых и JSON-полях базы (миграция 0035 — любая существующая
  база чинится сама при `db:migrate`); описание (alt) копии переходит к оригиналу, если у того нет.
- Оригинал в группе: тот, что используется, с большим разрешением, с alt.
- **Копии не вернутся:** сид ссылается на адреса CDN Duda — `content/seed/media-aliases.json` (75 адресов) говорит, какой
  это файл; `scripts/migrate-media.ts` новый скачанный файл сверяет по содержимому (SHA-1) с медиатекой и, если такой
  есть, не заводит второй. Проверено на пустой базе: весь путь сборки — 171 файл, 0 скачиваний; все 813 адресов
  `/uploads/…` в содержимом существуют.

## Как искали
1. SHA-1 файлов — побайтовые копии.
2. «Отпечаток» картинки (dHash 8×8) у картинок, обложек видео и первых страниц PDF — кандидаты в почти-копии; затем
   попиксельная разница на 480 px и просмотр глазами каждой пары.
3. Видео: длительность и три кадра (25 / 50 / 75 %) через ffmpeg (imageio-ffmpeg во временном окружении).
