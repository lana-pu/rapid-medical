# «Create from a document» — проба на SUCCESS и DISTALS (2026-11-16)

Открытые технические вопросы из `docs/flows/site-pages.md → Страница исследования`: извлечение текста из реальных PDF и
поля ClinicalTrials.gov. Текст брали тем же механизмом, что рисует страницы PDF (`media.text`, pdfjs в ветке
`site-redesign`, `src/lib/document-pages.ts`).

## Извлечение текста

| | SUCCESS (статья JNIS, 7 стр.) | DISTALS (слайды ESOC, 20 шт.) |
|---|---|---|
| Порядок чтения | правильный: заголовок, авторы, аннотация, колонки по очереди | правильный: слайд за слайдом |
| Цифры | все в тексте («conducted at 17 US centers», «Ninety consecutive patients») | в тексте, включая подписи осей графиков («0% 50% 60% …») |
| Дефекты | перенос слов «Wide- necked», «Oni- Orisan» (13 мест); колонтитулы и врезки между абзацами | цифры с графиков вперемешку с текстом; сноска прилипает к числу («N=541» — вероятно «N=54» + сноска 1) |

**Вывод.** Для «Text of this document» и для проверки цитат текста достаточно. Сверка цитаты с PDF должна выравнивать
пробелы и переносы («Wide- necked» = «Wide-necked»), лигатуры и регистр. Число со сноской — повод для «Check», а не
для автоматического «проверено»: человек смотрит на слайд.

## ClinicalTrials.gov (API v2, бесплатно, без ключа)

- **SUCCESS — NCT04518670** (номер есть в тексте PDF): наблюдательное, завершено, 90 пациентов (фактически), старт
  2020-11-24, первичное завершение 2024-05-01, центров в реестре **8** (США).
- **DISTALS — NCT05152524** (в слайдах номера нет, найден поиском «DISTALS Tigertriever»): завершено, 149 включено —
  совпадает со слайдом «Enrolled 149», рандомизировано 118.
- Поля для паспорта: тип и дизайн (allocation, masking), фазы, включено (actual/anticipated), статус, даты старта и
  завершения, список центров со странами.

## Расхождение

**Центров у SUCCESS: в статье 17, в реестре 8.** Паспорт, собранный из реестра, разошёлся бы со статьёй. Правило для
паспорта: у каждого значения — источник (документ или реестр); при расхождении показывается значение из одобренного
документа, расхождение — «Check» в админке (гипотеза; решение за владелицей).
