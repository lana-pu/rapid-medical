## Админка: расхождения, найденные при описании экранов (2026-11-13, не безопасность)

- Список Site pages: кнопка «+ New page» ведёт на 404; массовые Unpublish/Delete видны, но молча ничего не делают.
- Список: сообщение «Deleted.» никогда не показывается; «Published N item(s)» считает отмеченные, а не опубликованные;
  статус и регион кодами (`published`, `global`), а не словами; у Events две колонки по одному полю `startsOn`.
- Broken links: при неверном адресе назначения сообщения нет (`?error=1` не читается).
- Activity: в Prev/Next строка поиска не кодируется (`&`, `#` ломают листание).
- Массовое Delete — без проверки роли, ревизии и чистки черновиков (уже в `admin-record-edit.md`).
