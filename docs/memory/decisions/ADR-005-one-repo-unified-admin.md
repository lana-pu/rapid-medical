# ADR-005 — Один репозиторий и единая админка на сайт и инструмент

**Статус:** принято · **Дата:** 2026-11-05 · **Кто:** владелица

## Контекст
Есть два продукта: сайт Rapid Medical (миграция с Duda) и обучающий инструмент Tigertriever. Их пользователи пересекаются.
Текущая админка сайта запутанная.

## Решение
- Оба продукта живут в репозитории `lana-pu/rapid-medical`.
- Админка общая: вход, затем выбор, сайт или инструмент. Проектируется заново и детально, вместе для обоих продуктов.
- Сайт: миграция и визуальный редизайн, структуру сильно не меняем.

## Следствия
- Ресёрч инструмента предлагал отдельный стек на Supabase (`docs/tigertriever/research/platform-research-full.md`).
  Он написан до этого решения, стек нужно пересмотреть.
- Гипотеза на проектирование: общие вход, роли и медиатека, контент раздельно. У инструмента замороженные релизы
  и рынки, которые не совпадают с регионами сайта.
- Репозиторий публичный; владелицу это на текущей стадии устраивает, бюджетные данные из материалов убраны.
