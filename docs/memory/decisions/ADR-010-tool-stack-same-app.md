# ADR-010 — Стек инструмента Tigertriever: тот же Next.js, та же база, пакет — из зафиксированных ревизий

**Статус:** предложение, ждёт владелицы · **Дата:** 2026-11-16 · Связано: ADR-005 (один репозиторий, единая админка),
ADR-003 (черновики и живое), ADR-004 (хранилище), ADR-006 (работа в админке), `spec.md → Инструмент Tigertriever`,
BACKLOG «Сейчас» п. 5 (офлайн-пакет на машинах клиента) и п. 6

## Контекст

- Платформенное исследование инструмента (`docs/tigertriever/research/platform-research-full.md`) предлагало отдельный
  стек на Supabase. Оно написано до ADR-005 и помечено устаревшим; замены не было.
- ADR-005: один репозиторий, общая админка — вход, роли, 2FA, журнал, медиатека, черновики и история общие; контент
  раздельный. Рынки инструмента ≠ регионы сайта. Инструмент бесплатный.
- Врач получает **офлайн-пакет** (ZIP, открывается с `file://` без сети) с зафиксированным содержанием; маркетинг правит
  уроки в Content Studio и собирает пакеты (`spec.md → Состояния и публикация`). Формат данных пакета описан (формат 1,
  2026-11-11); учебный прототип v0.6 рисуется только из этого объекта.
- У сайта уже есть всё, что нужно Studio: Next.js + Postgres (Drizzle), вход с 2FA и ролями, журнал, медиатека с
  драйверами хранения, черновики / ревизии / история / комментарии, проверки перед Publish.

## Решение (предложение)

1. **Content Studio — раздел того же приложения** (`/admin/tool/…`, выбор «Website / Training tool» после входа), та же
   база. Новые таблицы (Drizzle, миграциями как у сайта): модели, ручки, рынки (со списком ручек), конфигурации,
   уроки (раздел программы × конфигурация), пары сравнения, пакеты. Медиа — общая таблица `media` + таблица метаданных
   инструмента (версия файла, исходник съёмки, готовность «Confirmed / Review first / Filming needed / No filming»).
2. **Черновики, ревизии, история, комментарии — существующие механизмы** (ADR-003, `drafts` / `revisions`): урок — ещё
   один ресурс. Save не меняет пакет (как сайт: сохранение не публикует).
3. **Рендер урока — один компонент** без серверных зависимостей: им рисуются Preview в Studio и офлайн-пакет. Для
   пакета он собирается в небольшой статический бандл (esbuild), который читает `window.TT_PACKAGE` из `content.js`.
4. **Publish = сборка пакета на сервере:** выбранные конфигурации и пары → проверки (блокеры из спеки) → ZIP из
   **зафиксированных ревизий уроков и версий медиа** (`index.html`, бандл, `content.js`, медиафайлы) → файл в хранилище
   (ADR-004) + запись пакета (версия, рынок, состав, ревизии, размер, контрольная сумма) → «Download» для проверки и
   отметка «Sent». Пакет никогда не пересобирается из живых данных: другая сборка — другая версия.
5. **Отдельного сервиса нет** — ни Supabase, ни второго приложения: одна авторизация, одни роли, одна медиатека,
   один деплой.

## Почему не Supabase / отдельное приложение

Второй вход и вторые роли противоречат ADR-005; медиатеку, черновики, историю, журнал пришлось бы делать заново или
синхронизировать; два деплоя и две базы для бесплатного инструмента с одним небольшим редакторским штатом. Выигрыша
(realtime, готовый storage) инструмент не использует: пакет офлайновый, редакторов единицы.

## Условие и риски

- **Офлайн с `file://` на машинах клиента не проверен** (BACKLOG п. 5, тестовый ZIP S0 готов). Если больничные
  компьютеры не откроют пакет с диска (политики браузера, Edge, блок ZIP), меняется только упаковка (например,
  установщик с локальным просмотрщиком или PWA с офлайн-кэшем); Studio, данные и рендер остаются.
- **Размер пакета** с видео (8 этапов × конфигурации) — замерить на материалах клиента; при необходимости пакет на рынок,
  а не на все конфигурации.
- Кто нажимает Publish (MED-08), промо-формулировки, предупреждения — вопросы маркетингу, на стек не влияют.

## Следствия

- `spec.md → Инструмент Tigertriever`: заменить «кода нет» на ссылку на этот ADR после принятия; таблицы — в
  `spec.md → Данные`, когда начнётся код.
- Прототип Content Studio v0.1 и учебный v0.6 переносятся в код по экранам (`/new-feature`), рендер урока — первым:
  он нужен и Preview, и пакету.
