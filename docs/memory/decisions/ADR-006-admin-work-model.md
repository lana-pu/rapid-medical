# ADR-006 — Как люди работают в единой админке

**Статус:** принято (решения владелицы), детали уточняются прототипом · **Дата:** 2026-11-06

## Контекст
Разбор текущей админки: `findings/admin-ux-review.md`. В админке будут работать 3–4 человека.

## Решение
- **Роли по сути две.** Редактор меняет тексты и картинки и собирает новые страницы по шаблонам. Дизайнер может менять дизайн полностью.
- **Правка на самой странице, по аналогии с редакторским доступом Webflow (2026-11-07).** Страница выглядит как страница.
  Клик по тексту или картинке начинает правку. Редактор может выделить блок, сдвинуть его и добавить новый блок из пресетов.
  Оформление блоков ему недоступно. Пример: прототип редактора, ссылка в `BACKLOG.md`.
- **Отдельного согласования нет, ни на сайте, ни в инструменте.** Одобрение — это кнопка Publish, её нажимает тот же человек,
  что работает с контентом. Если нужен просмотр коллегой, страница или урок отправляются ему, и хватает комментариев на месте,
  по аналогии с Figma. Роль approver и статусы ревью уходят.
- **Регионы по случаю.** Часть страниц есть только в конкретных регионах, часть почти совпадает и отличается картинками.
  Разница между регионами подсвечивается.
- **Меню и футер редактируются,** но это второстепенный экран.
- **Библиотека компонентов для дизайнера** — желаемое, не первая очередь.

## Следствия
- Новая возможность: шаблоны страниц. Сейчас `pages` — только rich text, блоков по шаблону нет.
- Новая возможность: порядок блоков и пресеты на существующих страницах. Сейчас порядок секций на странице терапии зашит в шаблоне,
  поэтому страницы надо хранить как упорядоченный список блоков.
- Новая возможность: комментарии, привязанные к месту на странице.
- Упрощение: статусы сводятся к «Черновик», «Опубликовано», пометке «есть правки» и дате, если запланировано.
- Ресёрч инструмента описывает отдельный шаг одобрения (FS-11, A-08, A-09). Это решение его отменяет: одобрением считается публикация.
  Вопрос MED-08 для маркетинга теперь звучит так: кто у клиента имеет право нажимать Publish на инструменте.
