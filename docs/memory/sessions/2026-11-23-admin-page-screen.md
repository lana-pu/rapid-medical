# 2026-11-23 — Экран страницы (Content): иерархия

**Задача:** следующий экран админки тем же циклом, что Home: разбор с Mobbin → решения владелицы → код.

## Что сделано
- Разбор и черновик: https://claude.ai/artifact/EoNmYGU46LoTY8GZsjCWuF (приватная ссылка). Референсы: Webflow
  Locales, Vercel, Flodesk, Later, Wix CMS, Circle, Mintlify, Framer.
- Решения владелицы: одна главная «Edit on page ▾»; одинаковые сниппеты Google склеивать (вопрос «как править один
  регион» → ссылки «Edit {регион}» на форму региона в Search & sharing, склейка только в показе); коллекции страницы-
  списка — первыми. Замечание по черновику: поползла вёрстка на телефоне — причина в одноколоночной сетке без
  `minmax(0,1fr)`; исправлено и в черновике, и учтено в коде.
- В коде (`83103295`): шапка с меткой шаблона и `EditMenu`; полоса состояния страницы (пилюли с подсказками); регионы
  таблицей (на телефоне строка складывается); Performance со столбиками за 30 дней (`pageDetails.byDay`) и «Came from»;
  Google со склейкой и шкалами длины; файлы компактно; `SectionHead`/`Calm`/`quietLink` — общие в `ui.tsx`.
- Проверки: tsc, lint, unit 242; замер 9 экранов × 7 ширин — 0 проблем. e2e не прогоняли (общая база).

## Находки
- Одноколоночная CSS-сетка растёт до самого широкого ребёнка (таблица, nowrap) — всегда `grid-cols-[minmax(0,1fr)]`.
- Колонки «таблицы» из отдельных grid-строк выравниваются, только если у `auto`-колонки фиксированная ширина.
