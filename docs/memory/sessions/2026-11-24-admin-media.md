# 2026-11-24 — Media: Upload в шапке, видео с кадрами, описание первым в карточке файла

**Задача:** следующий экран админки по полоске тем же циклом, после того как владелица закрыла Analytics («ok»).

## Что сделано
- Разбор «как сейчас»: у всех 50 видео есть постер, но в сетке — серая заглушка; PDF — пустые плашки; «No description»
  у всех 161 картинки (и у неиспользуемых); полоса загрузки над сеткой; в карточке файла имя — заголовком 30 px
  (на телефоне в пять строк), описание — в самом низу.
- Mobbin: Squarespace Asset Library, Shopify (файл и Files), Webflow Asset details, Mailchimp. Черновик:
  https://claude.ai/artifact/NGi4YLPxbASwkJ6uHkfWwL. Ответы владелицы (через вопросы) — все три рекомендации.
- Код (`27917bee`):
  - `MediaDrop` + `UploadButton` (`MediaGrid.tsx`): Upload в шапке «All files», бросить файлы — на всю медиатеку
    (подсветка «Drop to upload»); пунктирная полоса — только в пустой медиатеке. Подсказка «Drop files anywhere…» — с `sm`.
  - Сетка: постер у видео (`posterUrl`), значок документа у PDF, «где стоит · размер» строкой, «No description» только
    у картинок, которые стоят на сайте. `SortSelect` — сортировка без Apply.
  - Карточка файла: «← Media», тип меткой, имя `text-xl break-all`, вес · размеры · дата; справа одна карточка —
    Description (`AltField` с `hint`) → Used in N places → `ReplaceButton compact` → File details (`details`) → Delete.
  - Очередь описаний: «← Media» кнопкой у заголовка; подзаголовки групп и секций — без капслока.
- Спека: `screens/admin-media.md → «Иерархия»`, «Список», «Файл».
- Скриншоты: https://claude.ai/artifact/VXmMgR7R1UCZ3V86QqYxUC.
