# 2026-11-20 — Вайрфреймы рисуют настоящие блоки сайта

**Задача:** ответить, работают ли вайрфреймы на дизайн-системе или на хардкоде, и перевести их на систему (вариант 2:
настоящие компоненты в серой теме токенов).

## Что сделано
- Разбор: дизайн-система в коде собрана (9 токенов, примитивы, 24 блока, `/style-guide`), остатки хардкода описаны в
  DESIGN.md. Вайрфреймы брали из системы только данные (реестр, составы страниц), вёрстка блоков была ручной копией в
  `blocks-kit/page.template.html`: без `events` и `passport`, варианты от 2026-11-15 рисовались как вариант по умолчанию.
- `blocks-kit/render.sh`: генерирует все флоу → `render.cjs` собирает узлы `rm-page` / `rm-<блок>` → временный маршрут
  `src/app/flows-render` (копия `render-page.tsx` + `boundary.tsx`, удаляется после) → Playwright берёт HTML каждого узла
  и CSS → `rm-render.json` → `make-pack.py` → `pack.js`.
- `BlockList` получил необязательный `slot` — обёртка блока там, где он стоит; группировка блоков в вайрфрейме теперь та же,
  что на сайте, без дубля логики. Сайт `slot` не передаёт.
- CSS сайта ограничен `.rmx`, `md:`/`lg:` → `@container frame` (телефон 390 в вайрфрейме = мобильная вёрстка).
  Серая тема — только переназначение токенов (`wf-theme.css`, таблица в DESIGN.md → «Вайрфреймы»).
- Медиа → серые плашки с именем файла в пропорциях оригинала; карта мира (мегабайты путей) — тоже плашка.
- Экраны «как было» (`site-pages`, id с `asis`) рисует код до редизайна `99932794`: `render-asis.sh` сам поднимает
  worktree, клонирует node_modules, ставит тот же `slot`, рендерит и убирает всё.
- Проверка: 111 узлов текущих флоу и 16 «как было» без ошибок, на досках 0 предупреждений, JS-ошибок нет; tsc, 224 теста.

## Принятые решения
- Вайрфреймы — снимок настоящих компонентов, не своя вёрстка; новый вариант блока попадает в вайрфрейм через `render.sh`.
- История («как было») — кодом своего времени, снимок один раз.
- Шапка, футер, баннер региона пока остаются в паке (не блоки).

## Находки
- Turbopack не принимает node_modules по симлинку; APFS-клон (`cp -cR`) — мгновенно.
- Набор вайрфреймов задаёт `button, input { font: inherit }` вне слоя — перебивает утилиты Tailwind; в теме возвращаем
  `revert-layer`.
- `Img` держит blur-плейсхолдер в inline `background` — при замене на плашку его надо снимать.
- `common.strip` резал `generalHref` и др. — настоящим компонентам нужны все поля (Link без href падает).
