# 2026-11-23 — Home админки: иерархия, здоровье сайта, инфографика

**Задача:** владелица — пройти Home админки (`/admin/website`) через Mobbin по best practice, выстроить визуальную
иерархию; затем иконки и инфографика с подсказками, Site health ярче, «Coming up» не в центре.

## Что сделано
- Разбор с Mobbin (Shopify, Mintlify, Vercel, Wix, PandaDoc, Squarespace, GitBook, Substack), черновик и сверка
  «было → стало»: https://claude.ai/artifact/TWvjBrXSDxjQJDtfPMM8eT (приватная ссылка).
- Решения владелицы: Edit/View — и в шапке, и в карточке сайта; быстрые действия — ряд кнопок; неделя — справа;
  Site health — заметнее; Coming up — вниз (это запланированные публикации и ближайшие события с регистрацией).
- В коде (`c61aa3dd`): три уровня — карточка сайта → дела и здоровье сайта → неделя/журнал/впереди. Здоровье —
  карточки проблем с числом, шкалой, «почему важно» и действием; пройденные проверки — зелёные пилюли. Неделя —
  столбики по дням для визитов и заявок, полосы долей по формам и источникам. Подсказки `Tip`, иконки `icons.tsx`.
- Данные: `health()` отдаёт все проверки с итогами; в отчёте аналитики `leadsByDay` (unit-тест).
- Спека: `docs/screens/admin-home.md → «Иерархия»`, `admin-analytics.md`.

## Находки
- Подсказка с `opacity: 0` всё равно расширяет страницу (абсолютный элемент участвует в прокрутке) — скрывать
  `display: none` до наведения.
- Палитра долей — эталонная категориальная из гайда dataviz (порядок проверен на дальтонизм), «Other» — серый.
