# 2026-11-09 — Сверка библиотеки блоков с сайтом, текстовые страницы, Contact и About на блоках

**Задача:** проверить, все ли типы элементов сайта есть в библиотеке, и начать закрывать недостающее.

## Что сделано
- Сверка: все шаблоны сайта, записи `pages`, 73 скачанные страницы Duda против реестра. Итог и таблицы —
  `findings/block-inventory.md → Сверка с реестром блоков`.
- Новые блоки: Rich text, Media (`image`, `video`, `document`), Form (`default`, `compact`), Offices and map
  (`offices`, `map`).
- Новые варианты: Hero `page`; Text `large`, `surface`, `dark`; Call to action `light`; People `team`.
- На блоках теперь: текстовые страницы из `pages` (глобальные и региональные), `/about-us`, `/contact-us`.
  Адаптеры — `src/blocks/from-pages.ts`. Хранение не менялось.
- Простые блоки подряд идут в одной белой секции: поле `flow` в определении блока, группировка в `BlockList`.
- Спеки: новые `screens/about-us.md`, `screens/pages.md`; блоки в `screens/contact-us.md`; `DESIGN.md → В коде`.
- Тесты: 7 unit на адаптеры, e2e витрины дополнен (новые блоки, форма на витрине не отправляется).

## Проверка
- HTML основной части 20 адресов совпадает до и после в режиме посетителя и в режиме редактора. Нормализация: разделители
  React, идентификаторы server action, одна метка потоковой отдачи на первой компиляции. 40 полей `data-e` на About.
- 13 страниц терапий не изменились, оба режима.
- После слияния с Fix List: `tsc`, `lint`, `vitest` 29, e2e 41/41 на production-сборке.
- Витрина просмотрена на 1280 px; на 390 px нет горизонтальной прокрутки, ошибок в консоли нет.

## Изменённые файлы
- `src/blocks/*` (rich-text, media, form, offices-map, from-pages — новые), четыре шаблона страниц
- `tests/unit/blocks-pages.test.ts`, `tests/e2e/site.spec.ts`
- `docs/DESIGN.md`, `docs/spec.md`, `docs/screens/{about-us,pages,contact-us}.md`, `findings/block-inventory.md`

## Принятые решения
- Hero `page` — отдельный вариант: `title` остаётся полосой с линией снизу, `page` идёт в одной секции с содержимым.
- Тип формы (`contact`, `careers`, `webinar`) — поле блока, вариант отвечает только за вид.
- Форма на витрине показывается внутри `fieldset disabled`, чтобы не создавать настоящие заявки.
- Постеры, видео и PDF из `pages` остаются внутри `bodyHtml` до хранения страницы списком блоков, поэтому Media пока
  только на витрине. Так же Text `dark` и Call to action `light`: начнут работать при переводе главной и списка терапий.

## Находки
- Отступ через `className` у `E`/`EMedia` есть только в режиме редактора. Посетитель не видит `mt-8` у текста страниц и
  `mt-10` у картинки About: она стоит вплотную к тексту. Сохранено ради совпадения HTML, решить при дизайне.
- В отчёте сверки сначала было неверно сказано, что Hero `title` тёмный; исправлено в инвентаре.
- Параллельная сессия применила Fix List клиента во время работы; конфликт только в `contact-us/page.tsx`
  (их метаданные + блоки), решён при rebase.

## Открытые вопросы / следующие шаги
- Шаг 2: Gallery, News, Publications, Webinars, Jobs, Region chooser; варианты Text and media (на белом с кнопками,
  «проблема») и Columns `principles`. После этого на блоки переходят главная, Careers, Evidence, список терапий,
  News & Events, Webinars, выбор региона, вакансии.
- Хранение страницы списком блоков — после модели регионов.
- DISTALS results — пересобрать из блоков как лендинг, когда появится хранение блоками.
