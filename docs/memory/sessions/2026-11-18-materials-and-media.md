# 2026-11-18 — Одна сущность «материал», Create from a document, возврат потерянного, чистка медиатеки

**Задача:** ADR-009 шаги 1–2 и порядок в контенте после переноса с Duda. Работа в копии `main` (`../rapid-medical-main`,
ветка `materials`, своя копия базы `rapid_medical_materials`) параллельно ветке зависимостей во второй сессии.

## Что сделано
- **В `main` (документы):** флоу врача пересобран под сайт после редизайна (свежий снимок, окно региона, Evidence,
  Contact); разбор 73 «Not used» файлов; письмо Emily — 31 открытый вопрос (`docs/meetings/emily-letter-2026-11-18.md`).
- **Материалы (ADR-009 шаг 1):** `materials` вместо `publications` + `news_items` + страниц-материалов из `pages` (миграция
  0032, перенос 1:1, id публикаций сохранены, старые адреса работают); админка — **Publications & news**.
- **Create from a document (шаг 2, BACKLOG п. 8):** PDF → вид по файлу → сводка своим ИИ → черновик из секций → проверка
  каждой цитаты по тексту PDF и реестром ClinicalTrials.gov → Publish закрыт до «Looks right» (миграция 0033).
- **Возвращено с Duda:** графики LVO в своих секциях, «Leave nothing behind» на APAC Aneurysm, тексты карточек In-Practice
  (Aneurysm, три региона).
- **Featured на Evidence по регионам,** как на Duda (миграция 0034).
- **Медиатека — одна копия каждого файла:** 246 → 171, −132 МБ (миграция 0035, `media-aliases.json`, сверка содержимого в
  `migrate-media`); схемы обеих ручек расставлены по регионам.

## Принятые решения
- Владелица: вариант (а) развилки п. 8; «в новостях» — простой флаг; список — «Publications & news»; Create from a
  document — только PDF, реестр (документ главнее), проверка в карточке записи; Featured — по регионам; слайдер Evidence и
  блок цитаты врача — в бэклог.
- Материал с секциями показывает на своей странице секции (правятся на странице); без секций — прежний шаблон.
- Граница проверки: правка человека после «Looks right» не пересверяется (спека экрана).
