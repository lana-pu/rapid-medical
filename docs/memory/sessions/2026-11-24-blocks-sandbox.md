# 2026-11-24 — Песочница блоков /lab/blocks: модель, выделение, медиа, панель настроек

**Задача:** редактор — поправить баги и сложить набор компонентов из базовых блоков с вариантами; сначала проверить
модель на странице с реальными компонентами (песочница), потом переносить в редактор.

## Что сделано
- **Баги редактора (до песочницы):** капс сохранялся капсом, в демо не правились новые секции, не правились поля
  10 блоков — исправлено (`821b6186`, `33db050e`); переключатель роли Editor / Designer в демо (`032314d9`).
- **Песочница `/lab/blocks`** (только демо и локальная разработка — на проде отдала бы список медиатеки): секция →
  колонки → базовые блоки (заголовок, текст, кнопки, медиа, цифры, карточки, факты, цитата, список, вкладки) →
  готовые секции; правка текста на месте; данные — в localStorage браузера.
- **Выделение и навигация:** одно выделенное, хлебные крошки, «назад» и Esc; цвет выделения от реального фона (WCAG
  3:1); тихая рамка 1 px с ярлыком только у выбранного; скрытые колонки не теряют блоки; drag-and-drop секций и блоков.
- **Медиа:** реальная медиатека (вкладки, поиск, папки, метки); выбор файла — окошко рядом с панелью; картинка (формат,
  кадр, фокус, подпись, описание, картинка для телефона, по клику — ссылка / увеличить), видео (файл или YouTube /
  Vimeo, по умолчанию без звука по кругу с Play / Пауза, обложка, субтитры .vtt, звук — последним), документ; фон секции
  фото / видео с заполнением, Play и затемнением; просмотр «Компьютер / Телефон» во фрейме.
- **Панель настроек** (итерации по замечаниям владелицы): визуальные контролы → основное / «Дополнительно» →
  по темам (всё про картинку в «Картинке», «Ещё» внутри группы) → по правам (редактор — содержимое, дизайнер — вид),
  пустая панель свёрнута, без пояснялок → компактный вид по Mobbin (Framer, Subframe, Webflow, Klaviyo): строки 28 px,
  сегменты на серой дорожке, выбранное значение под подписью, поля залиты, тихое «Удалить». **Владелица: «устраивает».**
- Безопасность: ссылки картинок и адреса субтитров — только пути сайта и http(s) (`safeHref`, тест `lab-links`).
- Демо пересобиралось после каждого шага из копии базы (`pg_dump | psql` → `rm_demo_export`, заявки не на
  `@example.com` удалены в копии, копия удалена) → `gh-pages/redesign/`.

## Принятые решения
- Права в панели: редактор меняет содержимое (файлы и всё про них, количество, названия вкладок, файл фона), вид и
  раскладку — дизайнер (`model.ts → EDITOR_KEYS`). Это сужает прежнее «варианты переключает редактор» — владелица
  приняла работу панели 2026-11-24; при переносе в редактор свериться с ADR-006 → «Права».
- «По клику» у картинки — один выбор (ничего / ссылка / увеличить) вместо двух конфликтующих настроек.
- Видео по умолчанию — фон без звука по кругу с кнопкой Play / Пауза (WCAG 2.2.2).
