# 2026-11-08 — Единая админка: модель работы, правка на странице, коллекция блоков

**Задача:** спроектировать единую админку на сайт и инструмент Tigertriever так, чтобы в ней разобрался человек
без технического опыта (сессия 2026-11-06 … 2026-11-08).

## Что сделано
- Разбор текущей админки: 12 сценариев редактора, 7 причин путаницы, пересечение с инструментом
  (`findings/admin-ux-review.md`).
- ADR-006 — модель работы: редакторы и дизайнер; согласования нет, одобрение = Publish на обоих продуктах; просмотр
  коллегой через комментарии; регионы с подсветкой разницы; меню и футер второстепенны.
- Прототип v0.1 единой админки (Artifact KZ6xb3czzMdkpbAmxxjuMP). Владелица: «удобством не пахнет».
- Best practices для нетехнических редакторов и честный разбор прототипа v0.1: 11 проблем, паттерны «берём / не берём»,
  регионы через наследование, словарь, 5 заданий для проверки на людях (`findings/admin-editor-best-practices.md`).
- Решение владелицы: правка на самой странице по аналогии с редакторским доступом Webflow, блоки двигаются и
  добавляются из пресетов (ADR-006 дополнен).
- Прототип редактора на реальной странице Large vessel stroke (Artifact 9o31C5ccVdxUV52w2JKZxv): клик по тексту и
  картинке, перетаскивание блоков с уменьшением страницы, 7 пресетов, Undo, Preview, Publish с проверкой пустых полей.
  Прокликан в Chromium локально.
- Инвентарь всех секций сайта: 52 страницы, 134 секции, 30 типов → предложено 20 блоков (12 контента, 4 списка,
  4 системных) (`findings/block-inventory.md`); наглядный каталог со скриншотами (Artifact DvtThriAGQngpkvNTeddy5).
- Контракт блоков в `DESIGN.md → Коллекция блоков`: поля, варианты, права редактора и дизайнера (предложение).

## Принятые решения
- Одобрение = Publish, согласования нет, комментарии вместо него: ADR-006.
- Правка на странице, блоки двигаются и добавляются из пресетов: ADR-006.
- Регуляторный блок закреплён в конце страницы и не удаляется редактором: предложение в прототипе и DESIGN.md, ждёт
  подтверждения.

## Находки
- Сайт уже размечает редактируемые поля атрибутами `data-e` (ресурс, id, поле) — мост между прототипом и реальным
  on-page editor.
- Порядок секций на странице терапии зашит в шаблоне, данные лежат полями записи; половина секций не вынесена в
  компоненты. Блочная модель = смена модели данных (страница как список блоков).
- Регионы различаются целыми блоками (APAC LVO: картинка вместо видео; APAC Evidence без Featured publications).
- Заголовки рядов терапий разрезаны со времён Duda: надзаголовок «Gain active», H2 «control».
- Контролируемых исследований «правка на странице против формы» для CMS не нашли; Lullabot (2012): правка на странице
  хуже для скрытых полей, регионов и многошаговой работы → гибрид.

## Открытые вопросы / следующие шаги
- Владелица: обратная связь по прототипу редактора; подтверждение состава коллекции блоков.
- Модель регионов (наследование, кроме регуляторных блоков) и какая версия базовая — вопрос к клиенту.
- Вынос блоков в компоненты, страница как список блоков (BACKLOG → Сейчас, п. 1).
- Проверка на 2–3 будущих редакторах по 5 заданиям.
- Точечный UX-проход по сайту — предложен, не начат.
