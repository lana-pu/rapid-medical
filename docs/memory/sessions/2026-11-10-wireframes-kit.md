# 2026-11-10 — Набор для вайрфреймов и флоу редактора сайта

**Задача:** владелица хочет общую библиотеку для вайрфреймов, чтобы собирать флоу для любого проекта, и на ней смотреть
UX-решения Rapid Medical. Первым — редактор сайта.

## Что сделано
- Библиотека блоков Rapid Medical как вайрфреймы (приватная ссылка): https://claude.ai/artifact/9UHNuEdzXgzFdZRQ2jNN2H —
  22 блока, 55 вариантов, общие компоненты, анатомия, реальные тексты, сборщик страниц. В репозиторий не положена.
- Общий набор в воркспейсе (репозиторий Studio, коммит `d437536`): скилл `/wireframes`
  (`.claude/skills/wireframes/`: 54 компонента, доска со стрелками, прототип, библиотека, проверка флоу) и метод
  `modules/design/prompts/wireframes.md`. Библиотека (приватная ссылка): https://claude.ai/artifact/7jBJpiSU21xY4uTxU2DNPw
- Флоу «Site editor» — `docs/flows/site-editor.json` (+ генератор `site-editor.py`), 12 экранов в трёх группах: найти
  страницу → править на странице → регионы, публикация, откат. Заметки — решения с основаниями из
  `findings/admin-editor-best-practices.md` и ADR-006. Ссылка (приватная): https://claude.ai/artifact/LkArx5FdPAWQQqCvsigRP8

## Принятые решения
- Набор общий для всех проектов, флоу и паки компонентов — в проекте (`docs/flows/`). Решение владелицы.
- Флоу — JSON, страница — артефакт: Flow (доска), Prototype (клики), Library. Повторяющиеся кнопки шапки — `quiet`.

## Находки
- Временная папка сессии чистится системой: пропали `.env`, база и пакеты копии проекта. Для проверок поднят Postgres из
  Postgres.app (порт 55432, TCP, без сокета: путь длиннее 103 байт). Генераторы и данные держать в репозитории.
- В тексте флоу регионы названы как на сайте (Americas, Europe & Middle East, Asia & Pacific), а не US/OUS/APAC.
