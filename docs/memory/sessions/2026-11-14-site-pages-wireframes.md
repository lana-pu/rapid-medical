## Принятые решения
- Публикации, новости, исследования, кейсы, документы (IFU, брошюры) — одна сущность «материал» с видом; своя страница по
  желанию; дизайн по виду; вебинары и видео — следующий вид; knowledge base = все материалы с фильтрами: **ADR-009**.
- Featured: новые отмечены по умолчанию, галочку можно снять — закрывает BACKLOG №13.
- ИИ без оплаты: сайт ИИ не вызывает, маркетинг прогоняет инструкцию в своём чате; проверка цитат по тексту PDF.
- `/open-positions` → 301 на `/careers#open-positions`; выбор региона — модальное окно, страница — запасная.
