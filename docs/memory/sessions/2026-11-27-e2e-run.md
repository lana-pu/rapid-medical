# 2026-11-27 — Полный прогон e2e на своей базе; гонка редактора после Publish

**Задача:** «прогони e2e» после переделки экранов админки (списки и форма, Inbox, Analytics, Media, Settings), затем
«почини тест истории в редакторе».

## Что сделано
- e2e — на отдельной базе `rapid_medical_e2e` того же кластера: подготовка e2e стирает базу, а общую `rapid_medical`
  держит dev-сервер :3600 владелицы и параллельных сессий. Перед стартом проверено, что `DATABASE_URL` из окружения
  сильнее `--env-file=.env` у скриптов сброса. Как запускать — `memory/infrastructure.md`.
- Первый прогон: 88 тестов, 79 прошли, 2 упали, 7 пропущены (serial-файлы). Исправлены тесты (`5fbb94e1`):
  - Home: «Visits counted since» — в блоке This week, под ссылкой (так с `c61aa3dd`), тест искал в ссылке;
  - вход: сервер не принимает один код дважды в 30-секундном окне — `login` в `helpers.ts` ждёт новое окно и повторяет;
  - My account: девять проверок пароля (медленный хеш) — тесту 150 с.
- **Гонка редактора (`ab135545`):** окно «Live now» появлялось до того, как редактор узнавал новую версию страницы;
  правка сразу после «Keep editing» уходила со старой версией → «This page was changed by someone else». То же после
  Discard. Теперь окно — после `afterChange()`. Спека — `screens/on-page-editor.md → Публикация`.
- Итог: все тесты проходят; история — 4/4 отдельными запусками, `editor.spec` 15/15 дважды.

## Находки
- `--repeat-each` гоняет тест без сброса базы: тест истории портит себе данные (вторая итерация начинает с заголовком
  первой) — счёт «1 из 3» был ложным. Нестабильность мерить отдельными запусками.
- Отладочная копия теста с лишними `await` между шагами скрывала гонку — замедление меняет порядок.
- `next build` для e2e пишет в `.next`, dev — в `.next/dev`: сборка не мешает dev-серверу.
