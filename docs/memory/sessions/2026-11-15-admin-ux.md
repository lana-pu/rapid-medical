# 2026-11-15 — админка глазами пользователя: дашборд, Inbox, экран страницы, Settings, Google-тексты, медиатека

**Задача:** пройтись по окнам админки, сравнить с принятыми практиками и убрать нелогичное — экран за экраном с владелицей.

## Что сделано
- **Ревью окон** (30 экранов) → `docs/audits/admin-ux-review-2026-11-15.md`; прогон «глазами новичка» →
  `docs/audits/admin-walkthrough-2026-11-15.md` (гипотеза, проверка с Emily — позже).
- **Проекты и дашборд:** выбор проекта отдельной страницей, проект в шапке со стрелкой назад; дашборд проекта —
  что требует действия, быстрые действия, что впереди, здоровье сайта, последние действия склеены. «This week» — цифры
  с первого дня, «counted since», пока счётчику меньше недели.
- **Назад** везде ведёт туда, откуда пришли (стрелка в шапке, Back записи, ← редактора); прямая ссылка — на уровень выше.
- **Inbox как Gmail:** список на всю ширину, пока письмо не открыто; два фильтра (состояние · форма); все папки видны,
  Subscribed с выгрузкой для Mailchimp. **Заявка как письмо:** кто и когда сверху, текст крупно, детали справа;
  открыто = прочитано; Reply открывает готовое письмо; Done, Spam, кто отвечает — сразу; заметки лентой (миграция 0021).
- **Экран страницы — один экран:** регионы строками с Publish и Create from, производительность, превью в Google,
  файлы с превью (PDF в окне); вкладка **Differences between regions** — тексты и файлы по регионам рядом, правка на
  месте, Asia & Pacific скрыт (глазик), группы = секции страницы. Смена адреса при публикации → 301.
- **Списки и формы словами:** фильтры в строку, миниатюры, статусы и регионы словами; регион записи сервер держит после
  создания.
- **Settings:** открывается обзором блоками (что меняет и где видно, что требует внимания); группы с заголовками;
  People/Activity/Redirects/Broken links словами; **Search & sharing** — Google-тексты всех страниц в одном месте
  (список с проблемами, редактор с превью по регионам), у Home/About/Careers/Evidence/Therapies свои поля (миграция 0022).
- **Медиатека в порядке:** колонка групп слева, собранных по месту использования (страницы сайта по разделам, Other pages,
  списки, Site settings), Not used, No description, типы; страница сайта — файлы по секциям; карточка говорит, где файл
  стоит; сортировка; неиспользуемые удаляются пачкой после списка или со страницы файла.
- Ревью безопасности по ходу: безопасные схемы ссылок, `safeLocalPath` для всех сохранённых адресов в админке, регион
  на сервере, текст ошибки сохранения не уходит в интерфейс.

## Принятые решения
- Reply по заявке — готовое письмо (mailto); встроенная почта отложена, пока не ясно, в каком почтовом инструменте работает команда.
- Asia & Pacific сейчас не используется — скрыт по умолчанию в сравнениях (`PAUSED_REGIONS`).
- Аналитика — гибрид: свой счётчик без cookie + GA4 у маркетинга.
- Медиатека: умные группы по месту использования; ручные папки — не сейчас.
- Share preview страницы не делаем: правят 1–2 раза в месяц, согласуют внутри команды.

## Находки
- Машина под нагрузкой (load 9–16): e2e с тяжёлыми переходами флакают — таймауты 20 с на утверждение, перезапуск.
- Обзор Settings через `seoPages()` медленный — счётчик проблем отдельным SQL (`seoProblemCount`).
