# 2026-11-15 — Закрытые страницы сайта в коде (ветка `site-redesign`)

**Задача:** перенести решения по вайрфреймам (DESIGN.md → «Решения по страницам») в рабочий сайт — по одной странице:
спека → блоки → страница → тесты → коммит. Код — в отдельной ветке и worktree, в `main` пока не влито.

## Что сделано
- **Worktree** `projects/rapid-medical-redesign`, ветка `site-redesign` (запушена в origin). `node_modules` — APFS-клон
  (симлинк ломает Turbopack). Dev-сервер ветки — порт 3300 (3000, 3100, 3200 заняты другими).
- **Своя база ветки** `rapid_medical_redesign` (копия локальной через `pg_dump`, тот же кластер 55432; `.env` worktree
  указывает на неё). Миграции и полный e2e (сбрасывает базу) гоняются на ней, не трогая базу `main` и параллельную сессию.
- Страницы в коде (каждая — спека экрана + DESIGN.md «в коде с 2026-11-15» + юнит и e2e):
  - Contact Us (2fc65e4) — «общая линия», чипы тем, страна вместо региона, State только США/Канада, ошибки у поля, токен `--danger`.
  - Юридические страницы (2e0e847, 82b7cc1) — Rich text · `document`: дата редакции, «On this page», список Legal.
  - About (3a59348) — Text · `facts` (факты: страны, публикации — считаются, офисы — из Contact details, HQ), имена в
    обычном регистре + 2 строки био + «Read full bio», карточки офисов с «Get directions», карта как была. Миграция 0021.
  - Careers (06bb800) — Jobs · `roles` (фильтры отдел/город, первые 6, «Show all N roles», честное пустое состояние),
    кнопка шапки вниз по странице, форма кандидата в «общей линии» (EEO свёрнут, LinkedIn/CV, без Organization),
    буквы R·A·P·I·D; `/open-positions` → 308 `/careers#open-positions`. Миграция 0022.
  - Обзор терапий (a4d9952) — заголовок группы только при 2+ терапиях, одиночные одним рядом с направлением на карточке,
    «Explore →» и «N publications →» (как на Evidence); плашка «not available» и `?missing=` убраны;
    `/us/mvo`, `/us/vasospasm` → `/us/therapies` (сид + миграция 0023).
  - Выбор региона (169b59e) — модальное окно `RegionModal` (перехватывает ссылки на `/choose-your-location`): поиск
    страны, три карточки со странами из той же таблицы, что IP (`REGION_COUNTRY_CODES`), «Current region» с
    «From your location» / «Your choice» (cookie `rm_region_chosen`); страница — запасной путь без JS.

## Принятые решения
- Код редизайна — в ветке `site-redesign`, слияние в `main` целым куском после полного e2e на продакшн-сборке.
- Вакансии пока из записей `jobs` (подключение Spark Hire — вопрос к Emily); фото на карточках терапий — когда будут
  рендеры (BACKLOG №22); пустых рамок-обманок не ставим.
- Порядок стран в выборе региона — порядок таблицы (основные рынки первыми), не алфавит.

## Находки
- `next/link` обрабатывает клик раньше обработчика на `document` в фазе всплытия — перехват ссылок только в capture.
- Dev-сервер медленный после правки общего layout (главная 14–23 с): e2e с несколькими переходами упираются в лимит
  60 с — это не дефект; на прогретом сервере / с `--timeout` проходят.
- Падают и в `main` (ветка их не трогала): «history: restore an earlier version» (редактор, `/apac/therapies/mvo`);
  тест безопасности жёстко ждёт порт 3100; «activity log» и «content mode» зависят от порядка тестов.
