# Бриф фичи: «Create from a document» (BACKLOG п. 8, ADR-009 шаг 2)

## Намерение
Маркетинг делает страницу материала из PDF за несколько минут, без дизайнера и без оплаты ИИ проектом. Сайт сам достаёт
текст PDF и сверяет с ним всё, что предложил ИИ. Цифра, цитата которой не нашлась в PDF, не уходит на сайт без человека.
Вайрфреймы: `docs/flows/site-pages.md → Страница исследования` (экраны imp-new, imp-prompt, imp-review); проба на реальных
PDF — `memory/findings/create-from-document-probe-2026-11-16.md`.

## Аудитория
Маркетинг Rapid Medical в админке. Посетители видят готовую страницу материала (шаблон «Страница из документа»).

## Решения владелицы
- 2026-11-14: сайт ИИ не вызывает. «Copy instructions for AI» → ИИ маркетинга (ChatGPT / Claude / Copilot) → ответ
  вставляется в админку. Полный текст: скопировать / встроить PDF / только ссылка — выбор при создании. Хайлайты у
  нового включены по умолчанию.
- 2026-11-18 (интервью): первая версия — **только PDF** (загрузить или выбрать из медиатеки; ссылка на оригинал — поле).
  **Паспорт из ClinicalTrials.gov** по номеру NCT — да; при расхождении **главнее документ**, в админке «Check: registry
  says …». Проверка — **в карточке записи** (в редакторе на странице — следующим шагом).

## Как работает
1. **Выбор PDF.** Publications & news → «Create from a document» (и из срезов Evidence и News). Загрузить PDF или выбрать
   из медиатеки. Сайт рисует страницы и достаёт текст (как сейчас при загрузке).
2. **Что это за материал.** Сайт подсказывает вид по тексту, без ИИ, и пишет почему: «Instructions for Use» → документ;
   Methods + Results → исследование; «About Rapid Medical» / «Media contact» → новость; иначе публикация. Человек меняет
   одним кликом. Номер NCT находится в тексте сам, его можно поправить. Дальше: регионы, продукт, ссылка на оригинал;
   полный текст — скопировать / встроить PDF / только ссылка (по умолчанию: свои материалы — встроить PDF; публикация —
   только ссылка); где появляется — по виду (исследование — Evidence + новости; публикация — Evidence; новость — новости;
   случай и документ — нигде), хайлайт включён.
3. **Сводка своим ИИ** (у документа шага нет: только PDF). «Copy instructions for AI» копирует готовую инструкцию:
   ответ — JSON с заголовком, выводом одной фразой, 3–4 ключевыми цифрами и паспортом (у исследования). У каждой цифры и
   строки паспорта — точная фраза из документа. Человек прикладывает PDF в своём чате, вставляет инструкцию, потом
   вставляет ответ сюда.
4. **Черновик.** Сайт собирает материал-черновик из блоков страницы исследования: заголовок и вывод, ключевые цифры,
   паспорт (документ + реестр), документ на странице в выбранном режиме полного текста.
5. **Проверка.** Каждую цитату сайт ищет в тексте PDF без учёта пробелов, переносов, регистра и знаков. Нашлась, и
   цифра есть в цитате — «проверено». Иначе — «Check» с цитатой. Строка паспорта из реестра расходится с документом —
   «Check: registry says 8». В карточке записи — «3 of 5 checked», у каждого «Check» — цитата и «Looks right».
   Publish закрыт, пока остались непроверенные; сервер проверяет это сам, не только кнопка.

## Критерии успеха
- Из PDF SUCCESS (`/uploads/duda/…SUCCESS…pdf`) за один проход получается черновик исследования с цифрами и паспортом.
  Паспорт дополнен из NCT04518670; «Centers 17 / registry 8» — «Check».
- Выдуманная цитата или цифра, которой нет в цитате, — «Check», Publish закрыт; после «Looks right» — открыт.
- Документ (IFU): без шага ИИ, страница — PDF.
- Ответ ИИ с ошибкой формата — понятное сообщение, что не так; вставленное не теряется.
- ClinicalTrials.gov недоступен — черновик собирается без реестра, в карточке строка «Registry not reached».
- Только для вошедших редакторов; PDF — только из медиатеки сайта.
