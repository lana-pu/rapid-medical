# Бриф фичи: механизм блоков и основные блоки

## Намерение
Страницы сайта собираются из блоков. Блок описывается в одном месте: назначение, поля, варианты, компонент.
Похожие секции — один блок с вариантами, а не несколько блоков (решение владелицы 2026-11-08). Это основа для
редизайна (дизайнер перерисовывает блоки, а не страницы) и для редактора на странице (ADR-006).

## Аудитория
Сейчас — команда (дизайнер, разработка). Посетители изменений не видят. Редакторы получат блоки вместе с новым
редактором.

## Что делаем
1. **Реестр блоков** `src/blocks/`: тип, название, описание, варианты, поля, пример данных, компонент.
2. **Блоки с вариантами** — всё, что нужно страницам терапий:

   | Блок | Варианты |
   |---|---|
   | Hero | фоновое видео · картинка сбоку · только заголовок |
   | Text and media | медиа справа или слева · три колонки со второй картинкой; медиа — картинка, видео, цифры или график |
   | Text | обычный · крупный вводный |
   | Key numbers | круги · строка с иконками · бейдж |
   | Columns | шаги с медиа · преимущества с иконками |
   | Device diagram | — |
   | Spec table | таблица · картинки (старый формат) |
   | Call to action | тёмная полоса · тёмная плашка · ряд кнопок |
   | People | врачи (In practice) |
   | Video | тёмная полоса |
   | Product details | вкладки с блоками внутри |
   | Indications and references | — (системный, закреплён) |

3. **Перевод всех 13 страниц терапий** (US, OUS, APAC) на блоки. Шаблон один, поэтому переводятся сразу все.
4. **Витрина блоков** `/style-guide`: каждый блок во всех вариантах на примерных данных. Закрыта от индексации,
   не в sitemap.

## Как храним (решение архитектуры)
Данные терапий пока остаются в нынешних полях записи, а список блоков собирается из них при показе страницы.
Хранение «страница = список блоков» включим вместе с новым редактором: его форма зависит от модели регионов,
а она ещё не решена. Так не появится второй источник правды, и форма админки продолжит работать.

## Критерии успеха
- Все 13 страниц терапий выглядят как раньше: HTML основной части совпадает с версией до изменений.
- Правка на странице (on-page editor) работает на тех же полях, что и раньше.
- Новый вариант или блок добавляется в одном месте реестра.
- `/style-guide` показывает все блоки и варианты.
- `tsc`, `lint`, `npm test`, e2e зелёные.

## Исключения
- Не меняем внешний вид, модель данных и админку.
- Не переводим остальные страницы (главная, About, Careers, Evidence…) — следующий шаг.
- Не строим добавление и перестановку блоков — это новый редактор.
- Регионы и наследование не трогаем.
