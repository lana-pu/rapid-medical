# Админка: как она устроена (предложение, 2026-11-14)

Статус: **принято владелицей 2026-11-14** (четыре пространства; Inbox вместо главной; форма страницы — вкладка экрана
страницы). Спеки экранов — `docs/screens/admin-*.md`.
Основа: просьба владелицы 2026-11-14 («непонятно, как админка организована: дерево видно всегда, хотя нужно не везде,
функции дублируют друг друга»), структура сайта `docs/site-ia.md`, ADR-006 (роли, правка на странице).

## Что есть сейчас (инвентарь)
| Экран | Что делает | Пересекается с |
|---|---|---|
| `/admin/start` | развилка «Website / Training tool» | главная |
| `/admin` Home | «Needs your attention», последние действия, сводка | Requests, Activity, редактор (комментарии) |
| `/admin/editor` Find a page | все страницы карточками, New page | дерево слева, Pages в редакторе, экраны разделов |
| Дерево «Site» слева | страницы и коллекции | Find a page, Pages/Collections в редакторе |
| `/admin/page/…` экран страницы | регионы, коллекции, дочерние | экраны разделов |
| `/admin/site/{раздел}` экраны разделов | страницы, списки, настройки раздела | экран страницы (из меню убраны) |
| `/admin/{коллекция}`, запись, история | список записей, форма, версии | Collections в редакторе |
| Форма страницы (`/admin/solutions/12` и т. п.) | SEO, адрес, расписание | ⚙ Settings в редакторе, экран страницы |
| Редактор страницы | правка на месте; свои Pages, Collections, History, Comments, Regions | почти всё выше |
| Requests · Media library · Activity | работа | Home |
| Site settings (8 групп) · Redirects · Broken links · People · Account | настройки | Menu and footer в дереве; SEO у страниц |

**Итого:** к странице ведут 5 путей; настройки страницы и история — в 3 местах; «что ждёт меня» — в 3 местах;
Menu and footer и SEO — по 2–3 места. Дерево сайта видно на экранах, где оно не нужно (заявки, медиатека, настройки).

## Модель: три работы — три пространства (как Shopify, Webflow, Sanity)
Люди приходят в админку с одной из трёх задач. Каждой — своё пространство на полоске слева; **дерево сайта — только
в «Content»**, у остальных — свой список или ничего.

```
┌──┬──────────────────┬───────────────────────────┐
│📝│ Content          │  экран страницы / список   │  ← дерево сайта: страницы и коллекции
│📥│ Inbox (3)        │  заявки, комментарии, ждёт │  ← список «что ждёт», без дерева
│🖼│ Media            │  медиатека на всю ширину   │  ← без второй колонки
│⚙ │ Settings         │  группы настроек слева     │  ← свой список, как Settings в Shopify
│👤│ аккаунт          │                            │
└──┴──────────────────┴───────────────────────────┘
```

1. **📝 Content — «поменять сайт»** (по умолчанию). Вторая колонка — дерево сайта с поиском сверху (⌘K) и
   «+ New page». Клик по странице — **экран страницы**, единственное место её «паспорта» вкладками:
   *Overview* (регионы, статус, Edit on page ✎) · *Google & address* (бывшая форма страницы) · *History*.
   Клик по коллекции — её записи; запись — форма. Правка самой страницы — в редакторе (кнопка, ⌘E).
2. **📥 Inbox — «что ждёт меня»**: одна лента вместо Home + Requests + Activity: новые заявки, комментарии на страницах,
   неопубликованные правки и запланированные публикации, битые ссылки. Фильтры по виду. Заявка открывается справа
   (список → деталь, как в почте). Число на значке — всё, что требует действия.
3. **🖼 Media** — медиатека, без дерева.
4. **⚙ Settings — «как устроен сайт и кто в нём работает»** (редко): своя колонка групп —
   *Site*: Contact details · Social links · Regional notices · Google defaults · Branding (дизайнер) ·
   Integrations (админ) · Redirects; *Team*: People and roles (админ) · Activity log; *Account*.
   Menu and footer — **не здесь**, а в Content (это часть сайта, в дереве последним).

## Что уходит или сливается
| Было | Станет |
|---|---|
| `/admin/start` | убрать; когда появится Training tool — переключатель продукта над полоской |
| Home + Requests + «Needs your attention» | Inbox |
| Activity | Settings → Activity log (журнал) и строки «кто менял» на экранах |
| Find a page | поиск в дереве Content (⌘K) и «+ New page» над деревом |
| Экраны разделов `/admin/site/…` | экран страницы (матрица терапий — на экране Therapies, колонки регионов) |
| Форма страницы как отдельная запись | вкладка *Google & address* на экране страницы |
| Menu and footer в Settings | только в дереве Content |
| SEO-группа «Therapies overview (Google)» | вкладка *Google & address* у обзора терапий |
| Pages/Collections в редакторе | остаются (работа без выхода из редактора), это те же дерево и коллекции |

## Решения (2026-11-14)
1. Четыре пространства — да. 2. Inbox вместо главной, одна лента — да; Activity → Settings как журнал.
3. Форма страницы → вкладка экрана страницы — да.
